# Буквенные n-граммы для быстрой БЯМ

`ru_char4.npz` — модель по умолчанию для слота «быстрая БЯМ» (бэкенд `ngram`). Это буквенная 4-грамма с интерполированным сглаживанием Кнезера–Нея. Формат описан в `scripts/train_char_ngram.py`.

- **Алфавит:** 32 буквы, «ё» объединена с «е», плюс пробел, точка и запятая. Символы клавиатуры приводятся к нему: заглавные становятся строчными, `_` — пробелом.
- **Содержимое файла:**
  - таблица P(следующая буква | 3 предыдущие), 35³ × 35 значений в float16;
  - 40 000 частых слов для подсказок следующего слова.
- **Качество:** 2,47 бит на символ на предложениях `data/tasks_ru.txt`. Для сравнения: равномерное распределение — 5,13, старая mock-модель на маленьком корпусе — около 4,9. Задания не входят в обучающий текст, но вариант корпуса выбирался именно по этой цифре, поэтому её нельзя считать независимой оценкой (Q-39).

> Готовая словная KenLM-модель через окно оператора даёт заметно лучший результат: 1,91 бит на символ против 2,47–2,59. См. `models/kenlm/README.md`.

## Почему не готовая модель

Готовой открытой буквенной n-граммы для русского языка мы не нашли. Открытые русские KenLM-модели — словные, для распознавания речи (NVIDIA Riva/NeMo, wav2vec2 на Hugging Face). Их тоже можно использовать: бэкенд `kenlm` переводит словную модель в распределение следующей буквы. Эта 4-грамма остаётся лёгкой моделью, которая работает без скачивания, и запасной частью для KenLM, когда слово не нашлось в словаре.

## Данные (19.10.2026)

| Источник | Что взято | Ссылка |
|---|---|---|
| RussianNovels | 108 русских романов XIX–XX веков, полный текст (около 67 млн символов) | https://github.com/JoannaBy/RussianNovels (коммит 0398a12) |
| FrequencyWords, OpenSubtitles 2018, `ru_full.txt` | 1,19 млн слов с частотами из субтитров, то есть разговорная лексика. Слова добавлены как «слово + пробел» с весами; доля — 50 % всех символов | https://github.com/hermitdave/FrequencyWords (коммит 525f9b5), лицензия данных CC BY-SA 4.0 |

Новости Lenta.ru (https://github.com/yutkin/Lenta.Ru-News-Dataset) пробовали, но на разговорных фразах они ухудшают модель (сравнение при доле субтитров 15 %):

| Новости в корпусе | Бит на символ |
|---|---|
| 0 | 2,60 |
| 60 МБ | 2,66 |
| 200 МБ | 2,74 |
| все | 2,80 |

Поэтому в итоговую модель новости не вошли.

В файле только статистика (вероятности букв и список частых слов); текстов источников в нём нет.

## Как переобучить

```bash
git clone --depth 1 https://github.com/JoannaBy/RussianNovels
git clone --depth 1 https://github.com/hermitdave/FrequencyWords
python scripts/train_char_ngram.py --texts RussianNovels/corpus \
    --wordfreq FrequencyWords/content/2018/ru/ru_full.txt --wordfreq-share 0.5 \
    --order 4 --out models/ngram/ru_char4.npz
```

Любой другой корпус подключается ключом `--texts <папка с .txt>`. Получившийся `.npz` достаточно положить в эту папку: он появится в окне оператора в списке «модель».
