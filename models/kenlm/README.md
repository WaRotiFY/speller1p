# Словные n-граммы KenLM для быстрой БЯМ

Бэкенд `kenlm` («KenLM» в блоке «быстрая БЯМ» окна оператора) берёт готовую словную n-грамму и превращает её в распределение следующей буквы (MA-36). Модель указывается одним из трёх способов:

- **именем репозитория Hugging Face** — по умолчанию `jonatasgrosman/wav2vec2-large-xlsr-53-russian`, лицензия Apache-2.0. Спеллер скачивает `language_model/lm.binary` (1,49 ГБ) и `unigrams.txt` (33 МБ) один раз в `models/kenlm/<владелец>__<имя>/`, если отмечено «разрешить скачать». Файл `files.json` в этой папке хранит, откуда и когда скачано и какая версия (sha);
- **путём к файлу** `.arpa`, `.arpa.gz` или бинарному KenLM. Рядом может лежать `unigrams.txt`; для ARPA он не обязателен;
- **путём к папке** с такими файлами.

Скачанные модели в git не попадают (`.gitignore`).

## Сравнение на заданиях

`python scripts/compare_fast_lm.py ngram kenlm`. Считается по каждой букве 40 предложений из `data/tasks_ru.txt`, контекстом служит истинный предшествующий текст.

| Модель | Бит на символ | Верная буква — первая | — в тройке | Слово в топ-5 | Время: медиана / p95 |
|---|---|---|---|---|---|
| буквенная 4-грамма `ru_char4.npz` | 2,59 | 43 % | 68 % | 10 % | 0,01 / 0,08 мс |
| словная KenLM jonatasgrosman, λ = 0,1 | **1,91** | **59 %** | **81 %** | **32 %** | 0,6 / 220 мс |

- Доля буквенной 4-граммы λ = 0,1 оказалась лучше, чем 0,03 и 0,25.
- **Время.** 220 мс уходит в начале слова, когда перебираются все 60 000 слов словаря. Внутри слова — около миллисекунды. Это укладывается в длительность эпохи, потому что prior считается параллельно со стимуляцией.
- **Загрузка** занимает около 4 с, модель занимает примерно 1,5 ГБ оперативной памяти.
- **Оговорка:** состав обучающих текстов KenLM-модели не проверялся. Если среди них были бытовые фразы, похожие на задания, оценка завышена (Q-47).

## Установка пакета kenlm

Пакет на PyPI (0.3.0) не собирается под Python 3.13: сгенерированный Cython-код устарел. Работает сборка из исходников с перегенерацией:

```bash
pip install cython
git clone https://github.com/kpu/kenlm
cd kenlm
python -m cython -3 --cplus python/kenlm.pyx -o python/kenlm.cpp
pip install .
```

- **Linux и macOS:** нужен только компилятор C++ (`g++` или `clang`).
- **Windows:** нужны «Build Tools for Visual Studio» с компонентом «Разработка классических приложений на C++». На Windows эта сборка пока не проверялась.

Если пакет не установлен, окно оператора пишет об этом в блоке «быстрая БЯМ», а остальные модели работают как раньше.

## Без интернета или без доступа к Hugging Face

Если при старте сессии появилось «не удалось скачать … с https://huggingface.co», компьютер не может связаться с Hugging Face. Ошибка `getaddrinfo failed` означает, что не найден сам адрес сайта: нет сети, сайт закрыт в этой сети или нужен прокси. Что можно сделать:

1. **Зеркало.** Перед запуском спеллера задайте адрес зеркала, например `$env:HF_ENDPOINT = "https://hf-mirror.com"` в PowerShell или `set HF_ENDPOINT=https://hf-mirror.com` в cmd. Эту же переменную понимает и вариант «HF» (transformers).
2. **Вручную.** На компьютере с интернетом скачайте со страницы модели файлы `language_model/lm.binary` и `language_model/unigrams.txt` и положите их в папку `models/kenlm/<владелец>__<имя>/`. Для английской модели это `models/kenlm/jonatasgrosman__wav2vec2-large-xlsr-53-english/`, для русской — `models/kenlm/jonatasgrosman__wav2vec2-large-xlsr-53-russian/`. Спеллер возьмёт их без скачивания.
3. **Буквенная 4-грамма** (`ru_char4.npz`, `en_char4.npz`) лежит в репозитории и работает без сети.
