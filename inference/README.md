# Статистический вывод (Statistical Inference) — сменные модули

Каждый `*.py` в этой папке — один способ слить подсказку быстрой БЯМ (prior) с тем, что прислала физиология (правдоподобие). Окно оператора показывает все такие файлы в списке «Статистический вывод», а параметры из `PARAMS` — как поля ввода.

## Контракт (три пункта)

```python
"""Логарифмический пул (Байес)."""      # 1. первая строка docstring — название в списке

PARAMS = {                               # 2. параметры: значение по умолчанию и подсказка
    "alpha": {"default": 1.0, "min": 0, "max": 3, "step": 0.1, "label": "вес БЯМ α"},
}

def combine(prior, likelihood, params):  # 3. сама формула
    """prior, likelihood — numpy-массивы ЛОГАРИФМОВ вероятностей по символам клавиатуры
    (одинаковый порядок). Вернуть логарифмы апостериорных вероятностей того же размера;
    нормировать не обязательно — спеллер нормирует сам."""
    return params["alpha"] * prior + likelihood
```

- Функция вызывается после каждого обновления от физиологии, поэтому должна быть быстрой (миллисекунды).
- Если `combine` упала или вернула не то, спеллер пишет предупреждение в журнал и берёт только правдоподобие физиологии.
- В режиме «без БЯМ» модуль не вызывается: апостериорное распределение = правдоподобие физиологии (MA-13).
- Имя файла и значения параметров пишутся в каждую сессию (`posterior_computed.params`).
