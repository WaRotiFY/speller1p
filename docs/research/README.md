# Проектные материалы

Документы, по которым разрабатывался спеллер и готовится отчёт о методике. Для работы со спеллером они не нужны, но объясняют, почему он устроен именно так.

| Документ | Что в нём |
|---|---|
| `ASSUMPTIONS.md` | математические и экспериментальные допущения MA-NN: формулы, значения по умолчанию, риски, эксперименты для обоснования |
| `OPEN_QUESTIONS.md` | открытые вопросы Q-NN, принятые временные решения и кому их адресовать |
| `TRACEABILITY.md` | требования технического задания → модули → тесты и метрики |
| `REPORT_NOTES.md` | заготовки разделов отчёта |
| `PROTOTYPE_DESIGN_v3.md` | исходный проект прототипа: блоки схемы, контракты, режимы |

В коде решения помечены комментариями `# ASSUMPTION[MA-NN]`, `# STUB[Q-NN]` и `# IMPROV[Q-NN]`. `python scripts/check_markers.py` сверяет эти пометки с документами.

Документы отражают проект на момент написания. Если ссылка на файл в них устарела, актуальное устройство описано в [`../ARCHITECTURE.md`](../ARCHITECTURE.md).
