# REPORT_NOTES — черновик отчёта

## Назначение прототипа

Проверить поток данных v3 и воспроизводимую запись для будущей интеграции с физиологическим модулем. Все полученные числа — результаты **симуляции**, они **не являются проверкой требований ТЗ**.

## Архитектура и схема v3

`EpochRunner` связывает Primary Text, быструю модель, априорное распределение, физиологический контракт, слияние, детектор, медленную коррекцию, Secondary Text и запись. Расширения вынесены за основной цикл.

## Контракт с физиологическим модулем

Принимаются `EpochStart` и `PhysiologyObservation` в порядке 36 символов. Распределение обязано быть правдоподобием без языкового prior. Сейчас работает только симулятор; live-плагин выдаёт явный `NotImplementedError`.

## Интеграция БЯМ и обоснование выбора

Выбор модели задаётся конфигурацией. По умолчанию используется символьная n-грамма и словарная коррекция. Это не БЯМ. `bench-llm` измеряет bits-per-char, log p целевого символа, Top-N слова и p95 задержки. Выбор настоящих моделей требует EXP-01/02, лицензий, аппаратного профиля и согласия на передачу текста при облачном варианте.

## Запись и модель данных

Каталог `runs/<session_id>/` содержит манифест, полный конфиг, журнал JSONL, итоговые тексты, CSV-таблицы, производные метрики, ссылки на внешние данные и SHA-256. Экспорт пишет ZIP и отчёт о полноте.

## Методика оценки

Метрики рассчитываются только по сохранённым сессиям. Парное сравнение использует одинаковые задания и сиды для режимов с языковой моделью и без неё. Основная скорость — правильно введённые символы Primary Text за минуту; в отчёте отдельно показываются среднее и строгий критерий по нижней границе 95 % ДИ.

Контрольный прогон `configs/compare_llm.yaml` 29.09.2026: 10 симулированных участников, задания T001/T002, 40 сессий. Средняя скорость Primary Text: с mock-моделью 2,241 символа/мин, без неё 2,241 символа/мин. Парный прирост составил **+0,02 %** (95 % бутстреп-ДИ −1,80…+1,99 %). Средняя точность символа: 90,1 % и 89,8 % соответственно. Исправленный Secondary Text при mock-модели дал 1,912 символа/мин; восстановление исходно ошибочных слов — 0 %. Пороги скорости и пользы БЯМ не пройдены даже на симуляции. Эти числа не проверяют требований к реальному ЭЭГ.

`bench-llm` на 40 тестовых предложениях: 5,17 бит/символ; Top-10 следующего слова при пустом префиксе — 0 %. Это показывает, что fallback-корпус и n-грамма служат только проверке потока данных, а не качественной языковой подсказке.
