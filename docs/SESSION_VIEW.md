# Визуализация сессии: экран испытуемого и экран экспериментатора

Демонстрационный инструмент, в ТЗ его нет. `stimulus_kit/tools/open_data/session_view.py` открывает одно окно 1600×900 с двумя экранами. Он только слушает LSL-потоки спеллера и ничего в них не отправляет, поэтому сессию не меняет.

| Экран | Что показывает | Откуда |
|---|---|---|
| **Испытуемый** (слева) | матрица 6×6, вспыхивающие строки и столбцы (125 мс), набранный текст, подсказка «смотрите на X» (copy-spelling), подсветка выбранной буквы: зелёная — верно, красная — ошибка | `SpellerStimuli`, `SpellerControl`, `SpellerLikelihood`, цель из `SpellerReplayMarkers` |
| **Экспериментатор** (справа) | бегущая ЭЭГ всех каналов за 5 с с линиями вспышек (оранжевые — вспышка с целевой буквой); тепловая карта P(буква \| ЭЭГ) по матрице; пять лидеров; число оценённых вспышек и повторений; средний ответ «цель / не цель» по Cz/Pz/P3/P4 (видно, как растёт P300); набранный текст против задания и точность | `SpellerEEG`, `SpellerLikelihood`, `SpellerStimuli`, `SpellerReplayMarkers` |

ЭЭГ и средний ответ показываются через фильтр 0,5–12 Гц. Это только для глаз: декодер фильтрует по-своему. Средний ответ и подсветка целей работают, когда цель известна, то есть при проигрывании размеченной записи. В живой сессии без цели эти панели пустые.

Если работает настоящий спеллер, набранный текст берётся из его сообщений `result`, то есть с учётом языковой модели. Без спеллера, при проигрывании с судьёй, текст складывается из лучшей буквы в финальном правдоподобии.

## Запуск на записи BNCI 2014-008

Четыре окна, порядок не важен (см. `OPEN_DATA.md`):

```powershell
uv run --no-sync python stimulus_kit/tools/open_data/session_view.py
uv run --no-sync python stimulus_kit/decoders/external_pipeline_decoder.py run --model runs/A01.joblib --eeg-name SpellerEEG
uv run --no-sync python stimulus_kit/tools/eeg_source.py replay data/bnci2014_008/bnci2014_008_A01.edf `
    --marker-map stimulus_kit/tools/open_data/markers_bnci2014_008.json --as-stimulus --as-control --start 588.623
```

`--speed 1` (по умолчанию) — реальный темп: один символ около 38 с. Esc закрывает окно.

**Запись видео:** `--record demo.mp4 --fps 25`, нужен `ffmpeg` в PATH. Кадры пишутся по настенным часам, поэтому длительность видео совпадает с реальной. Без экрана: `SDL_VIDEODRIVER=dummy`.

Зависимости: `pip install pygame pylsl scipy numpy`.
