# EEG Speller — P300-спеллер с языковыми моделями

Программа для набора текста «взглядом»: на экране клавиатура, символы по очереди подсвечиваются или двигаются, а спеллер по ответу мозга (P300) и подсказке языковой модели решает, какой символ человек хотел набрать.

- **Экран испытуемого — сменный модуль.** Его рисует отдельная программа, например на pygame. Спеллер не знает, что на экране: он просит выбрать символ, получает вероятности символов от декодера ЭЭГ, складывает их с подсказкой языковой модели и сообщает выбранный символ. Связь только через LSL.
- **Быстрая языковая модель** подсказывает следующую букву: словная n-грамма KenLM, своя буквенная 4-грамма или любая нейросеть с Hugging Face по имени.
- **Медленная языковая модель** исправляет набранные слова: локальная через Ollama или облачная (OpenRouter, Groq, NVIDIA NIM, любой OpenAI-совместимый адрес).
- **Способ слияния** подсказки и ЭЭГ — сменный модуль на Python из папки `inference/`.
- **Запись.** Всё, что происходит в сессии, пишется в журнал с метками времени LSL — тех же часов, что у ЭЭГ.

Всё работает на одном компьютере, записи остаются в `runs/`.

## 1. Как это устроено

```
┌──────────── спеллер (python -m eeg_speller.external.server) ─────────────┐
│ быстрая БЯМ → подсказка ─┐                                               │
│                          ├→ статистический вывод → решение → текст        │
│ правдоподобие ЭЭГ ───────┘                     │            ↓            │
│ журнал событий (runs/…/events.jsonl)           │   медленная БЯМ (правки) │
└────────▲──────────────────────────▲────────────┼─────────────────────────┘
  SpellerLikelihood           SpellerStimuli   SpellerControl          (LSL)
         │                          │            ▼
   декодер ЭЭГ ◄── поток ЭЭГ ── модуль стимуляции (экран испытуемого)
```

Набор одного символа — это **эпоха**:

1. Спеллер считает подсказку быстрой БЯМ и отправляет модулю стимуляции `epoch_start`: клавиатуру и уже набранный текст.
2. Модуль показывает стимулы. Сразу после каждого кадра со стимулом он сообщает, какие символы подсвечены; метка ставится по часам LSL.
3. Декодер присылает правдоподобие символов. Спеллер сливает его с подсказкой после каждого обновления.
4. Когда уверенность выше порога, спеллер присылает `stop`, выбирает символ и отправляет его модулю, чтобы тот показал результат.
5. На конце слова медленная БЯМ в фоне исправляет последние слова.

Протокол между спеллером и модулями — [`stimulus_kit/CONTRACT.md`](stimulus_kit/CONTRACT.md). Устройство спеллера — [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## 2. Установка

Нужны **Python 3.12** (3.11–3.13), **Git** и **uv**. Команды даны для Windows PowerShell; на macOS и Linux они те же, только пути пишутся через `/`.

```powershell
winget install --id Git.Git -e
winget install --id astral-sh.uv -e
git clone -b release-0.2 https://github.com/biospellerorg/speller1p.git
cd speller1p
uv python install 3.12
uv venv --python 3.12
uv pip install -e ".[dev]"
uv run --no-sync python -m pytest -q
```

`uv pip install -e .` ставит всё, что нужно для работы: спеллер, LSL, pygame для модулей стимуляции, чтение EDF. `[dev]` добавляет тесты. Два тяжёлых варианта быстрой БЯМ ставятся отдельно, когда понадобятся:

| Команда | Что добавляет |
|---|---|
| `uv pip install -e ".[dev]"` | `pytest`, `pyarrow` — тесты и таблицы Parquet |
| `uv pip install -e ".[hf]"` | `transformers`, `torch` (несколько ГБ) — нейросети с Hugging Face |
| `uv pip install -e ".[replay]"` | `pyriemann`, `scikit-learn`, `joblib` — проигрывание реальной записи ЭЭГ и готовый декодер к ней (раздел 3) |
| `uv pip install -e ".[kenlm]"` | `kenlm` — словная n-грамма; нужен компилятор C++, на Python 3.13 — сборка из исходников ([`models/kenlm/README.md`](models/kenlm/README.md)) |

Все команды ниже запускаются из папки проекта через `uv run --no-sync`, активировать окружение не нужно.

## 3. Первый запуск без оборудования

```powershell
uv run --no-sync python -m eeg_speller.external.server
```

Откройте http://127.0.0.1:8770/, в блоке «физиология» выберите модуль **«Симулятор (без экрана)»** и нажмите **«начать сессию»**. Симулятор сам «набирает» фразу из своего `settings.json` (`sentence`), а окно показывает текст, буквы-кандидаты, уверенность и исправления.

С экраном: выберите модуль **«Мигание строк и столбцов»** и начните сессию. В его `settings.json` по умолчанию включены пробел вместо ЭЭГ и показ в окне: щёлкните по окну модуля и нажимайте пробел, когда подсвечена нужная буква.

### Реальная ЭЭГ вместо испытуемого

Спеллер можно проверить целиком на настоящих записях P300-спеллера. Есть две открытые записи, у каждой свой модуль:

| Модуль в окне оператора | Запись | Задание | Язык |
|---|---|---|---|
| «Проигрывание записи ЭЭГ: BCI Competition II (английские слова)» | BCI Competition II, IIb (Wadsworth): 1 человек, 64 канала, 240 Гц | `BCI2B_TEST` — `foodmoothampiecaketunazygot4567` | English |
| «Проигрывание записи ЭЭГ: BNCI 2014-008 (итальянские слова)» | 8 пациентов с БАС, 8 каналов, 256 Гц | `BNCI008_TEST` — `gattomenteviolarebus` | English, без БЯМ (слова итальянские) |

```powershell
uv pip install -e ".[replay]"
uv run --no-sync python stimulus_kit/tools/open_data/get_bci2_iib.py        # английская запись (~95 МБ)
uv run --no-sync python stimulus_kit/tools/open_data/get_bnci2014_008.py    # итальянская, участник A01 (~21 МБ)
uv run --no-sync python -m eeg_speller.external.server
```

В окне оператора выберите **язык** English, **задание** из таблицы (оно есть в списке заданий, вводить вручную не нужно) и **модуль**, затем нажмите «начать сессию». Модуль печатает загаданную фразу проигрываемой части записи в свой журнал. Задание нужно, чтобы спеллер сравнивал набранное с тем, что человек действительно набирал. Кроме того, при этом пропадает предупреждение «the task has characters missing on the keyboard»: оно появлялось, когда к латинской клавиатуре записи выбирали русское задание.

Как идёт эпоха:
- спеллер просит символ, модуль проигрывает следующий символ записи: ЭЭГ уходит в `SpellerEEG`, вспышки строк и столбцов — в `SpellerStimuli`;
- декодер `external_pipeline_decoder.py` (pyRiemann: xDAWN → касательное пространство → логистическая регрессия) присылает правдоподобие;
- спеллер сливает его с языковой моделью, решает, когда остановиться, и выбирает букву.

Декодер модуль запускает сам. При первом запуске он обучает модель на калибровочной части записи и сохраняет её в `runs/models/`. Окно модуля — экран испытуемого: матрица, вспышки и целевая буква из разметки записи. Если эпоха прервана (нет правдоподобия, Esc), тот же символ записи проигрывается снова.

Пробелов в обеих записях нет: слова набирали подряд. Поэтому медленная БЯМ по умолчанию запускается каждые 20 символов, а не по пробелам.

Запись, анализатор, темп и число калибровочных символов задаются в `settings.json` модуля (`stimulus_kit/modules/eeg_replay*/`). Данные, разметка, точность и офлайн-проверка декодера — в [`docs/OPEN_DATA.md`](docs/OPEN_DATA.md).

## 4. Окно оператора

Настройка разбита на блоки по частям спеллера. Выбор запоминается в браузере. Кнопка ◐ в шапке переключает тёмную и светлую тему.

| Блок | Что выбирается |
|---|---|
| **0 сессия** | участник; **язык** (русский / English: от него зависят алфавит, модели по умолчанию, задания и промпт); задание (свободный набор, фраза из `data/tasks_ru.txt` или `data/tasks_en.txt`, фразы открытых записей ЭЭГ из `data/tasks_open_data.txt`, своя фраза), «с БЯМ / без БЯМ» |
| **1 физиология** | модуль стимуляции из `stimulus_kit/modules/`. Только выбор: клавиатуру, параметры, режим проверки и подсказку цели задаёт сам модуль в своём `settings.json` (раздел 5) |
| **2 быстрая БЯМ** | 4-грамма, KenLM, нейросеть HF или mock (раздел 6) |
| **3 статистический вывод** | модуль из `inference/` и его параметры (раздел 6); порог досрочной остановки; пауза между эпохами |
| **4 медленная БЯМ** | выключена, «словарь» (без языковой модели: слово заменяется словом словаря, если по вариантам букв оно почти наверняка задумано, раздел 6) или «БЯМ по API»: провайдер, ключ, модель из списка провайдера; когда запускать: **каждые N символов** (по умолчанию 20, пробелы не нужны) или в конце слова (каждые N слов, окно из W слов); «передавать варианты букв»; кнопка «промпт» — редактор с предпросмотром запроса |

Если для выбранной модели не хватает пакета, при старте появится ошибка с командой установки, например `uv pip install -e ".[kenlm]"`.

Экран сессии:
- **сверху** — паспорт сессии: что выбрано (в том числе клавиатура, которую прислал модуль), время, номер эпохи;
- **по центру** — набираемый текст поверх задания (верные буквы светлые, ошибки красные), под ним исправленный текст и кандидаты слов;
- **слева** — топ-4 символа после БЯМ (ЭЭГ + БЯМ) и до неё (только ЭЭГ);
- **справа** — шкала уверенности с порогом остановки, стимулы, точность, скорость;
- **внизу** — история эпох: номер, цель, выбор (зелёный — верно, красный — ошибка), уверенность (жёлтая — ниже `detector.tau`), четыре самых вероятных символа, число стимулов, длительность, как принято решение и что исправила медленная БЯМ после этой эпохи. Старые строки затухают; «показать всё» раскрывает всю историю.

«Пауза» и «завершить» управляют сессией. При завершении модуль стимуляции закрывается сам. Если модуль упал, под кнопками появятся последние строки его вывода.

## 5. Модули стимуляции и декодеры

| Модуль | Стимул |
|---|---|
| `flash_rows_cols` | вспышки строк и столбцов |
| `moving_letters` | короткое движение буквы в случайный момент |
| `moving_circles` | кружок буквы пробегает по эллипсу |
| `simulator` | без экрана: виртуальный испытуемый и симулированная ЭЭГ |
| `eeg_replay`, `eeg_replay_bci2` | реальная запись ЭЭГ вместо испытуемого (BNCI 2014-008; BCI Competition II): на каждую эпоху — следующий символ записи; сам запускает декодер (раздел 3) |

- **Модуль самостоятельный.** Клавиатуру (`alphabet`, `num_rows`, `num_cols`), фразу для подсказки цели при copy-spelling и калибровке (`sentence`), пробел вместо ЭЭГ, полный экран, времена и цвета задаёт его `settings.json`. Клавиатуру модуль сообщает спеллеру при подключении, и спеллер подстраивает под неё языковую модель.
- **Свой модуль.** Положите папку с `main.py` (и, по желанию, `settings.json` и `module.json`) в `stimulus_kit/modules/`. Обязательных правил два: объявить клавиатуру в `SpellerLink(keyboard=…, layout=…)` и сразу после `flip` кадра со стимулом вызвать `link.flash([символы])`. Всё остальное — в [`stimulus_kit/CONTRACT.md`](stimulus_kit/CONTRACT.md).
- **Декодер ЭЭГ** — отдельный процесс, который присылает правдоподобие символов. Пример P300-декодера по любому LSL-потоку, проигрыватель EDF в LSL и калибровка описаны в [`docs/DECODER.md`](docs/DECODER.md). Готовый внешний анализатор на pyRiemann/scikit-learn — `stimulus_kit/decoders/external_pipeline_decoder.py` ([`docs/OPEN_DATA.md`](docs/OPEN_DATA.md)); проигрывание и ретрансляция чужих EDF/BDF и живого усилителя — [`docs/EEG_SOURCE.md`](docs/EEG_SOURCE.md).

Проверка всей цепочки на синтетической ЭЭГ одной командой:

```powershell
uv run --no-sync python -m eeg_speller.physiology.edf_demo --text "привет"
uv run --no-sync python scripts/run_external_demo.py edf
```

Модули стимуляции сначала ждут, пока спеллер подключится к их потокам, поэтому первые стимулы не теряются.

## 6. Языковые модели

**Язык.** Спеллер поддерживает русский и английский (блок «сессия», в профиле — `language: ru | en`, всё языковое — в `eeg_speller/core/language.py`). Язык задаёт алфавит языковой модели, модели по умолчанию, список заданий и промпт медленной БЯМ:

| | русский | English |
|---|---|---|
| 4-грамма | `ru_char4.npz` | `en_char4.npz` |
| KenLM | `jonatasgrosman/wav2vec2-large-xlsr-53-russian` | `jonatasgrosman/wav2vec2-large-xlsr-53-english` (Apache-2.0) |
| HF | `Qwen/Qwen2.5-0.5B` | `HuggingFaceTB/SmolLM2-135M` (Apache-2.0) |
| задания | `data/tasks_ru.txt` | `data/tasks_en.txt` |
| промпт | `prompts/correction_v3.txt` | `prompts/correction_en.txt` |

Если клавиатура модуля написана на другом языке, чем выбран для сессии, в журнале сессии появится предупреждение.

**Быстрая БЯМ** — подсказка следующей буквы в каждой эпохе:

| Вариант | Что это | Качество на заданиях* |
|---|---|---|
| **KenLM** | готовая словная n-грамма. По умолчанию `jonatasgrosman/wav2vec2-large-xlsr-53-russian` с Hugging Face (Apache-2.0, 1,5 ГБ, скачивается один раз в `models/kenlm` при отмеченном «разрешить скачать»; можно указать путь к своему `.arpa` / `.bin`). Следующая буква — сумма вероятностей слов из словаря (60 000 самых частых), продолжающих начатое слово; 10 % массы берётся от буквенной 4-граммы, чтобы не обнулять редкие слова и опечатки | 1,91 бит/символ, верная буква первая в 59 % |
| **4-грамма** | буквенная модель `models/ngram/ru_char4.npz` (английская — `en_char4.npz`, 2,21 бит/символ на `data/tasks_en.txt`), работает без скачивания | 2,59 бит/символ, 43 % |
| **HF** | любая causal LM с Hugging Face по имени, например `Qwen/Qwen2.5-0.5B`: модель должна выдавать распределение следующего токена (Qwen, ruGPT, T-lite…). Нужен `uv pip install -e ".[hf]"` | — |

\* `python scripts/compare_fast_lm.py ngram kenlm` на `data/tasks_ru.txt`. Подробности и оговорки — в `models/kenlm/README.md` и `models/ngram/README.md`.

**Медленная БЯМ** исправляет набранное. По умолчанию она запускается **каждые N символов** (`slow_llm.trigger: every_n_chars`, `every_n_chars: 20`), пробелы для этого не нужны. Каждое слово уходит на исправление один раз, а слово, которое ещё набирается, ждёт следующего запуска. Текст без пробелов уходит целиком. Прежний режим — в конце слова, каждые N слов (`trigger: word_end`). Варианты:
- **Словарь** — без модели и без сети, мгновенно. Для каждого слова берутся слова словаря той же длины, которые подходят к вариантам букв; если одно из них набирает ≥ 80 % оценки, оно заменяет набранное (`ножалуйста` → `пожалуйста`). Выбирать по смыслу (`на` или `не`) словарь не умеет — для этого нужна БЯМ.
- **Ollama.** Локальная модель на этом компьютере: `ollama pull qwen2.5:7b`, затем выберите модель из списка. Берите модель без рассуждений (не `qwen3`, `deepseek-r1`, `gpt-oss`): рассуждения медленнее, а для выбора слова из списка они не нужны.
- **Облачные провайдеры** дают бесплатный ключ, лимиты небольшие. Выбрав облачного провайдера, вы соглашаетесь, что последние набранные слова уходят ему. Ключ хранится только на этом компьютере (`~/.eeg_speller/keys.json`) и не попадает в записи сессий.

  | Провайдер | Где взять ключ | Лимиты |
  |---|---|---|
  | OpenRouter (модели `:free`) | openrouter.ai/keys | около 50 запросов в день |
  | Groq | console.groq.com/keys | около 30 в минуту, 1000 в день |
  | NVIDIA NIM | build.nvidia.com (регистрация в NVIDIA Developer) | — |
  | свой адрес | любой OpenAI-совместимый сервер: llama.cpp server, LM Studio | — |

- **Статистический вывод** — как слить подсказку быстрой БЯМ (prior) с правдоподобием ЭЭГ. Каждый файл в `inference/` — один способ: `log_pool` (по умолчанию, `α·log prior + β·log правдоподобие`; при α = β = 1 — формула Байеса), `linear_pool` (смесь вероятностей), `tempered_bayes`. Свой способ — новый файл с `PARAMS` и `combine(prior, likelihood, params)`, см. [`inference/README.md`](inference/README.md).
- **Похожие слова.** По вариантам букв, которые рассматривал спеллер, для каждого слова окна подбираются слова словаря той же длины (ошибка спеллера — замена буквы, а не пропуск) и показываются модели с оценкой: `нежно: нужно 83, нежно 17`. Модели остаётся выбрать по смыслу, с этим справляются и маленькие модели. Промпт по умолчанию — `prompts/correction_v3.txt`; прежний, где варианты букв перечислены по буквам, — `prompts/correction_v2.txt`. Изменённый промпт сохраняется в `prompts/user/` и записывается в каждую сессию.
- **Какую модель выбрать.** `scripts/bench_slow_llm.py` прогоняет модель на записанных ошибках симулированного набора и считает, сколько ошибок исправлено и сколько верных слов испорчено. Результат на 40 заданиях (d′ = 1,4; 40 ошибочных слов; модели — те же веса, что в Ollama, Q4_K_M, на процессоре без видеокарты):

  | Медленная БЯМ | Исправлено ошибочных слов | Испорчено верных | Ответ |
  |---|---|---|---|
  | словарь (без модели) | 18 из 40 | 0 из 152 | мгновенно |
  | `gemma3:4b` | 24 из 40 | 3 из 152 | ~5 с |
  | `llama3.1:8b` | 22 из 40 | 0 из 43* | ~11 с |
  | `qwen2.5:7b` | **28 из 40** | 0 из 152 | ~10 с |

  \* только окна с ошибками. На видеокарте ответ в 5–10 раз быстрее. Ошибки, при которых пробел набран не на месте («во изи» вместо «включи»), не исправляет никто: число букв в слове меняется.

## 7. Запись данных

Каждая сессия — каталог `runs/external/<сессия>/`:

```
session.json        паспорт: участник, задание, модели, версии, оборудование
config.yaml         полный снимок настроек (включая текст промпта)
events.jsonl        журнал всех событий — первичный источник
texts/              задание, набранный и исправленный текст
tables/             epochs.csv (одна строка на эпоху, с временной шкалой), corrections.csv
derived/            метрики и проверка полноты записи
external/           лог модуля стимуляции, промпт медленной БЯМ
checksums.sha256
```

- **Время.** Каждое событие имеет метку `lsl_s` в часах LSL. Для каждой эпохи пишется временная шкала: старт → первый стимул → правдоподобие отправлено и получено → стоп → решение → результат отправлен.
- **Правдоподобие** пишется и как его прислал декодер (`raw`), и нормированным.
- **Сырую ЭЭГ** спеллер не пишет. Её записывает LabRecorder (XDF со всеми LSL-потоками) или ПО усилителя.

Формат — [`docs/DATA_MODEL.md`](docs/DATA_MODEL.md).

## 8. Командная строка: симуляция, переигрывание, экспорт

| Команда | Что делает |
|---|---|
| `uv run --no-sync python -m eeg_speller run --config configs/default.yaml` | одна симулированная сессия: виртуальный участник набирает задание |
| `uv run --no-sync python -m eeg_speller experiment --config configs/compare_llm.yaml` | серия виртуальных участников с БЯМ и без; среднее, дисперсия, 95 % ДИ |
| `uv run --no-sync python -m eeg_speller replay runs/external/<сессия>` | переиграть записанную сессию: стимулы и правдоподобие ЭЭГ берутся из записи, языковые модели, слияние, остановка, решение и коррекция пересчитываются. `--llm off` — без БЯМ; `--config изменения.yaml` — частичный YAML поверх настроек сессии, например `external: {stop_confidence: 0.9}`. Печатает сравнение с исходной сессией и пишет новую сессию с `replay_of` |
| `uv run --no-sync python -m eeg_speller.external --profile configs/ext_replay.yaml --target "foodmoothampiecaketunazygot4567"` | спеллер без браузера для проигрывания записи (English, 4-грамма `en_char4`); модуль — во втором окне: `uv run --no-sync python stimulus_kit/modules/eeg_replay_bci2/main.py` |
| `uv run --no-sync python -m eeg_speller export runs/<сессия>` | упаковать сессию в ZIP с проверкой полноты |
| `uv run --no-sync python -m eeg_speller bench-llm --config configs/exp01.yaml` | качество быстрой модели на заданиях |
| `uv run --no-sync python scripts/compare_fast_lm.py ngram kenlm` | сравнить быстрые модели: бит на символ, точность буквы, топ-N слов, задержка |
| `uv run --no-sync python scripts/train_char_ngram.py --texts <папка .txt> ...` | обучить свою буквенную n-грамму |

- **Настройки** задаются YAML-профилями в `configs/`. Профиль может наследовать другой (`inherits: default.yaml`) и менять только нужные ключи.
- **Профиль окна оператора** — `ext_default.yaml`, **профиль симуляции** — `default.yaml`.
- **Заготовки переборов параметров** — `exp03.yaml`, `exp04.yaml`, `exp05.yaml`.

## 10. Если что-то не работает

| Что видно | Что сделать |
|---|---|
| «ждём модуль» в окне оператора | модуль стимуляции не запущен или упал — его последние строки видны под кнопками |
| ошибка `не установлен пакет …` при старте | выполнить команду из сообщения, например `uv pip install -e ".[kenlm]"` |
| модуль: `speller control stream 'SpellerControl' not found` | сначала начать сессию в окне оператора, потом запускать модуль вручную |
| KenLM: `не установлен пакет kenlm` | `uv pip install -e ".[kenlm]"`; если не собирается — `models/kenlm/README.md`, или выбрать 4-грамму |
| KenLM: `is not downloaded yet` | отметить «разрешить скачать» (≈1,5 ГБ) |
| медленная БЯМ: `no connection` | Ollama не запущена (`ollama serve`) или нет интернета |
| медленная БЯМ: `HTTP 401` / `HTTP 429` | неверный ключ / исчерпан бесплатный лимит провайдера |
| окно модуля открылось за браузером | щёлкнуть по нему на панели задач; на втором мониторе — проверить `window_x`, `window_y` в `settings.json` модуля |
