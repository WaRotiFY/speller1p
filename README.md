# EEG Speller — P300-спеллер с языковыми моделями

Программа для набора текста «взглядом»: на экране клавиатура, символы по очереди подсвечиваются или двигаются, а спеллер по ответу мозга (P300) и подсказке языковой модели решает, какой символ человек хотел набрать.

- **Экран испытуемого — сменный модуль.** Его рисует отдельная программа, например на pygame. Спеллер не знает, что на экране: он просит выбрать символ, получает вероятности символов от декодера ЭЭГ, складывает их с подсказкой языковой модели и сообщает выбранный символ. Связь только через LSL.
- **Быстрая языковая модель** подсказывает следующую букву: словная n-грамма KenLM, своя буквенная 4-грамма или любая нейросеть с Hugging Face по имени.
- **Медленная языковая модель** исправляет набранные слова: локальная через Ollama или облачная (OpenRouter, Groq, NVIDIA NIM, любой OpenAI-совместимый адрес).
- **Способ слияния** подсказки и ЭЭГ — сменный модуль на Python из папки `inference/`.
- **Запись.** Всё, что происходит в сессии, пишется в журнал с метками времени LSL — тех же часов, что у ЭЭГ.

Всё работает на одном компьютере, записи остаются в `runs/`.

## 1. Как это устроено

```
┌──────────── спеллер (python -m eeg_speller.external.server) ─────────────┐
│ быстрая БЯМ → подсказка ─┐                                               │
│                          ├→ статистический вывод → решение → текст        │
│ правдоподобие ЭЭГ ───────┘                     │            ↓            │
│ журнал событий (runs/…/events.jsonl)           │   медленная БЯМ (правки) │
└────────▲──────────────────────────▲────────────┼─────────────────────────┘
  SpellerLikelihood           SpellerStimuli   SpellerControl          (LSL)
         │                          │            ▼
   декодер ЭЭГ ◄── поток ЭЭГ ── модуль стимуляции (экран испытуемого)
```

Набор одного символа — это **эпоха**:

1. Спеллер считает подсказку быстрой БЯМ и отправляет модулю стимуляции `epoch_start`: клавиатуру и уже набранный текст.
2. Модуль показывает стимулы. Сразу после каждого кадра со стимулом он сообщает, какие символы подсвечены; метка ставится по часам LSL.
3. Декодер присылает правдоподобие символов. Спеллер сливает его с подсказкой после каждого обновления.
4. Когда уверенность выше порога, спеллер присылает `stop`, выбирает символ и отправляет его модулю, чтобы тот показал результат.
5. На конце слова медленная БЯМ в фоне исправляет последние слова.

Протокол между спеллером и модулями — [`stimulus_kit/CONTRACT.md`](stimulus_kit/CONTRACT.md). Устройство спеллера — [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## 2. Установка

Нужны **Python 3.12** (3.11–3.13), **Git** и **uv**. Команды даны для Windows PowerShell; на macOS и Linux они те же, только пути пишутся через `/`.

```powershell
winget install --id Git.Git -e
winget install --id astral-sh.uv -e
git clone https://github.com/biospellerorg/speller1p.git
cd speller1p
uv python install 3.12
uv venv --python 3.12
uv pip install -e ".[dev]"
uv run --no-sync python -m pytest -q
```

`uv pip install -e .` ставит всё, что нужно для работы: спеллер, LSL, pygame для модулей стимуляции, чтение EDF. `[dev]` добавляет тесты. Два тяжёлых варианта быстрой БЯМ ставятся отдельно, когда понадобятся:

| Команда | Что добавляет |
|---|---|
| `uv pip install -e ".[dev]"` | `pytest`, `pyarrow` — тесты и таблицы Parquet |
| `uv pip install -e ".[hf]"` | `transformers`, `torch` (несколько ГБ) — нейросети с Hugging Face |
| `uv pip install -e ".[kenlm]"` | `kenlm` — словная n-грамма; нужен компилятор C++, на Python 3.13 — сборка из исходников ([`models/kenlm/README.md`](models/kenlm/README.md)) |

Все команды ниже запускаются из папки проекта через `uv run --no-sync`, активировать окружение не нужно.

## 3. Первый запуск без оборудования

```powershell
uv run --no-sync python -m eeg_speller.external.server
```

Откройте http://127.0.0.1:8770/ и выберите:
- задание — фразу из списка, например `T001`;
- физиологию — программу **«Без экрана: симуляция вспышек и „мозга“»**.

Нажмите **«начать сессию»**. Симулятор сам «набирает» фразу, а окно показывает текст, буквы-кандидаты, уверенность и исправления.

С экраном и пробелом вместо ЭЭГ: выберите модуль «Мигание строк и столбцов», отметьте **«пробел вместо ЭЭГ»** и **«в окне»**, начните сессию. Затем щёлкните по окну модуля и нажимайте пробел, когда подсвечена нужная буква.

## 4. Окно оператора

Настройка разбита на блоки по частям спеллера. Выбор запоминается в браузере.

| Блок | Что выбирается |
|---|---|
| **0 сессия** | участник, задание (свободный набор, фраза из `data/tasks_ru.txt`, своя фраза), «с БЯМ / без БЯМ»; «показывать испытуемому целевую букву» — для copy-spelling и калибровки |
| **1 физиология** | модуль стимуляции из `stimulus_kit/modules/` или `stimulus_kit/examples/`. Параметры модуля из его `settings.json` — поля с подсказками; правки действуют только на одну сессию. Галочки «пробел вместо ЭЭГ» и «в окне» |
| **2 клавиатура** | алфавит 6×6, ЙЦУКЕН 4×11 с цифрами, ЙЦУКЕН 4×10 для набора или своя. Модуль получает клавиатуру в каждой эпохе |
| **3 быстрая БЯМ** | KenLM, 4-грамма, нейросеть HF или mock (раздел 6) |
| **4 статистический вывод** | модуль из `inference/` и его параметры; порог досрочной остановки; пауза между эпохами |
| **5 медленная БЯМ** | выключена, словарь (mock) или «БЯМ по API»: провайдер, ключ, модель из списка провайдера; «исправлять каждые N слов», окно из W слов, «передавать варианты букв»; кнопка «промпт» — редактор с предпросмотром запроса |

Экран сессии:
- **сверху** — паспорт сессии: что выбрано, время, номер эпохи;
- **по центру** — набираемый текст поверх задания (верные буквы светлые, ошибки красные), под ним исправленный текст и кандидаты слов;
- **слева** — топ-4 символа после БЯМ (ЭЭГ + БЯМ) и до неё (только ЭЭГ);
- **справа** — шкала уверенности с порогом остановки, стимулы, точность, скорость;
- **внизу** — история правок медленной БЯМ в виде чата.

«Пауза» и «завершить» управляют сессией. При завершении модуль стимуляции закрывается сам. Журнал эпох и вывод модуля — в «подробнее».

## 5. Модули стимуляции и декодеры

| Модуль | Стимул |
|---|---|
| `modules/flash_rows_cols` | вспышки строк и столбцов |
| `modules/moving_letters` | короткое движение буквы в случайный момент |
| `modules/moving_circles` | кружок буквы пробегает по эллипсу |
| `examples/pygame_matrix.py`, `examples/pygame_rsvp.py` | простые примеры: матрица и одна буква в центре |
| `examples/headless_sim.py` | без экрана, симуляция стимулов и ответа мозга |

- **Свой модуль.** Положите папку с `main.py` (и, по желанию, `settings.json` и `module.json`) в `stimulus_kit/modules/`. Обязательное правило одно: сразу после `flip` кадра со стимулом вызвать `link.flash([символы])`. Всё остальное — в [`stimulus_kit/CONTRACT.md`](stimulus_kit/CONTRACT.md).
- **Декодер ЭЭГ** — отдельный процесс, который присылает правдоподобие символов. Пример P300-декодера по любому LSL-потоку, проигрыватель EDF в LSL и калибровка описаны в [`docs/DECODER.md`](docs/DECODER.md).

Проверка всей цепочки на синтетической ЭЭГ одной командой:

```powershell
uv run --no-sync python -m eeg_speller.physiology.edf_demo --text "привет"
uv run --no-sync python scripts/run_external_demo.py edf
```

Модули стимуляции сначала ждут, пока спеллер подключится к их потокам, поэтому первые стимулы не теряются.

## 6. Языковые модели

**Быстрая БЯМ** — подсказка следующей буквы в каждой эпохе:

| Вариант | Что это | Качество на заданиях* |
|---|---|---|
| **KenLM** | готовая словная n-грамма. По умолчанию `jonatasgrosman/wav2vec2-large-xlsr-53-russian` с Hugging Face (Apache-2.0, 1,5 ГБ, скачивается один раз). Следующая буква — сумма вероятностей слов, продолжающих начатое слово | 1,91 бит/символ, верная буква первая в 59 % |
| **4-грамма** | буквенная модель `models/ngram/ru_char4.npz`, работает без скачивания | 2,59 бит/символ, 43 % |
| **HF** | любая causal LM с Hugging Face по имени, например `Qwen/Qwen2.5-0.5B` | — |

\* `python scripts/compare_fast_lm.py ngram kenlm` на `data/tasks_ru.txt`. Подробности и оговорки — в `models/kenlm/README.md` и `models/ngram/README.md`.

**Медленная БЯМ** исправляет последние слова после каждого N-го слова:
- **Ollama.** Локальная модель на этом компьютере: `ollama pull qwen2.5:3b`, затем выберите модель из списка.
- **Облачные провайдеры.** OpenRouter (модели `:free`), Groq и NVIDIA NIM дают бесплатный ключ без карты, лимиты небольшие. Ключ хранится только на этом компьютере (`~/.eeg_speller/keys.json`). Отправка набранного текста в облако включается отдельной галочкой.
- **Варианты букв.** В промпт можно передавать для каждой буквы окна top-K вариантов, которые рассматривал спеллер. Промпт по умолчанию — `prompts/correction_v2.txt`; изменённый промпт сохраняется в `prompts/user/` и записывается в каждую сессию.

## 7. Запись данных

Каждая сессия — каталог `runs/external/<сессия>/`:

```
session.json        паспорт: участник, задание, модели, версии, оборудование
config.yaml         полный снимок настроек (включая текст промпта)
events.jsonl        журнал всех событий — первичный источник
texts/              задание, набранный и исправленный текст
tables/             epochs.csv (одна строка на эпоху, с временной шкалой), corrections.csv
derived/            метрики и проверка полноты записи
external/           настройки и лог модуля стимуляции, промпт медленной БЯМ
checksums.sha256
```

- **Время.** Каждое событие имеет метку `lsl_s` в часах LSL. Для каждой эпохи пишется временная шкала: старт → первый стимул → правдоподобие отправлено и получено → стоп → решение → результат отправлен.
- **Правдоподобие** пишется и как его прислал декодер (`raw`), и нормированным.
- **Сырую ЭЭГ** спеллер не пишет. Её записывает LabRecorder (XDF со всеми LSL-потоками) или ПО усилителя.

Формат — [`docs/DATA_MODEL.md`](docs/DATA_MODEL.md).

## 8. Командная строка: симуляция, переигрывание, экспорт

| Команда | Что делает |
|---|---|
| `uv run --no-sync python -m eeg_speller run --config configs/default.yaml` | одна симулированная сессия: виртуальный участник набирает задание |
| `uv run --no-sync python -m eeg_speller experiment --config configs/compare_llm.yaml` | серия виртуальных участников с БЯМ и без; среднее, дисперсия, 95 % ДИ |
| `uv run --no-sync python -m eeg_speller replay runs/<сессия>` | переиграть записанную сессию с другими языковыми настройками: ЭЭГ из записи, остальное пересчитывается |
| `uv run --no-sync python -m eeg_speller export runs/<сессия>` | упаковать сессию в ZIP с проверкой полноты |
| `uv run --no-sync python -m eeg_speller bench-llm --config configs/exp01.yaml` | качество быстрой модели на заданиях |
| `uv run --no-sync python scripts/compare_fast_lm.py ngram kenlm` | сравнить быстрые модели: бит на символ, точность буквы, топ-N слов, задержка |
| `uv run --no-sync python scripts/train_char_ngram.py --texts <папка .txt> ...` | обучить свою буквенную n-грамму |

- **Настройки** задаются YAML-профилями в `configs/`. Профиль может наследовать другой (`inherits: default.yaml`) и менять только нужные ключи.
- **Профиль окна оператора** — `ext_default.yaml`, **профиль симуляции** — `default.yaml`.
- **Заготовки переборов параметров** — `exp03.yaml`, `exp04.yaml`, `exp05.yaml`.

## 10. Если что-то не работает

| Что видно | Что сделать |
|---|---|
| «ждём модуль» в окне оператора | модуль стимуляции не запущен или упал — см. «подробнее → программа стимуляции» |
| модуль: `speller control stream 'SpellerControl' not found` | сначала начать сессию в окне оператора, потом запускать модуль вручную |
| KenLM: `needs the kenlm package` | собрать пакет `kenlm` (`models/kenlm/README.md`) или выбрать 4-грамму |
| KenLM: `is not downloaded yet` | отметить «разрешить скачать» (≈1,5 ГБ) |
| медленная БЯМ: `no connection` | Ollama не запущена (`ollama serve`) или нет интернета |
| медленная БЯМ: `HTTP 401` / `HTTP 429` | неверный ключ / исчерпан бесплатный лимит провайдера |
| окно модуля открылось за браузером | щёлкнуть по нему на панели задач; на втором мониторе — проверить `window_x`, `window_y` в параметрах модуля |
