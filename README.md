# EEG Speller: прототип ЭЭГ-спеллера с языковой моделью

Исследовательский прототип P300-спеллера: на экране матрица 6×6 из русских букв, строки и столбцы по очереди подсвечиваются, а система по реакции человека и по подсказке языковой модели решает, какую букву он хотел набрать.

Экран испытуемого рисует **отдельная сменная программа** — например, демонстрация физиологов на pygame. Спеллер не знает, что на этом экране: он просит выбрать символ, получает вероятности букв от декодера ЭЭГ, складывает их с подсказкой языковой модели и сообщает выбранную букву. Как только уверенность достаточна, спеллер присылает сигнал «хватит, переходите к следующей букве». Связь — только через LSL; файлы ЭЭГ спеллер не открывает.

В комплекте есть примеры сменных модулей: матрица 6×6 и показ по одной букве (pygame), симулятор без экрана, P300-декодер и проигрыватель EDF в LSL. Для проверки без оборудования вместо ЭЭГ можно нажимать пробел.

Прежний браузерный режим, где спеллер сам рисует матрицу, тоже сохранён (раздел 4).

Всё выполняется локально; записи сессий остаются в `runs/`. Проверка на людях и на реальном усилителе ещё не проводилась.

## 1. Как это работает

Набор **одного символа** называется эпохой. В каждой эпохе происходит следующее:

```
 набранный текст ──► Быстрая модель ──► prior: какие буквы вероятны дальше
                                             │
 вспышки ──────────► ЭЭГ ──► декодер ──► правдоподобие: на какой букве была реакция
 (сменная программа          (сменный      │
  стимуляции)                 модуль)      ▼
                                    Слияние (Statistical Inference)
                                    posterior ∝ prior^α · правдоподобие^β
                                             │  уверенность ≥ порога ──► «стоп» программе стимуляции
                                             ▼
                                    Детектор: берёт самую вероятную букву
                                    (или повторяет эпоху, если не уверен)
                                             │
                                             ▼
                                    Первичный текст ──► (конец слова) ──► Медленная модель
                                                                          исправляет последние слова
                                                                                  │
                                                                                  ▼
                                                                          Исправленный текст
 Каждый шаг пишется в журнал сессии (events.jsonl).
```

Простыми словами:

1. **Быстрая модель** смотрит на уже набранный текст и говорит: «после „приве“ почти наверняка будет „т“». Это **prior** — 36 вероятностей, по одной на клетку.
2. **Вспышки и декодер.** Программа стимуляции подсвечивает буквы так, как задумали физиологи (например, строки и столбцы матрицы по нескольку раз), и после каждой вспышки сообщает, какие буквы горели и когда. Реакция на вспышку с задуманной буквой — это сигнал P300 в ЭЭГ. Декодер превращает её в **правдоподобие** для каждой буквы и присылает спеллеру; вместо ЭЭГ для проверки можно нажимать пробел.
3. **Слияние** перемножает prior и правдоподобие (логарифмический пул) и получает **апостериорное распределение**. Поэтому даже при слабом сигнале языковая модель «дотягивает» правильную букву.
4. **Досрочная остановка.** После каждого обновления от декодера спеллер пересчитывает распределение. Если лучшая буква набрала заданную уверенность (по умолчанию 0,99), он присылает программе стимуляции «стоп»: можно переходить к следующей букве. Программа вправе это игнорировать.
5. **Детектор** выбирает букву с максимальной вероятностью. Если уверенность ниже порога τ, он либо всё равно выбирает её с меткой «неуверенно» (режим `label`), либо повторяет попытку (режим `abstain`).
6. **Результат** отправляется программе стимуляции, чтобы она показала испытуемому выбранную букву.
7. **Медленная модель** после каждого слова пробует исправить опечатки в последних словах. Её результат ведётся отдельной строкой — **исправленный текст**, первичный текст не меняется.
8. **Запись.** Все распределения, решения, тексты и тайминги пишутся в каталог сессии, поэтому любую сессию можно проанализировать и прогнать заново с другими настройками.

Режим **«без БЯМ»** — то же самое, но prior равномерный, а коррекция и подсказки слов выключены. Сравнение двух режимов на одних и тех же «участниках» — основа требования ТЗ о приросте скорости на 20 %.

Подробно: [`docs/EXTERNAL_MODULES.md`](docs/EXTERNAL_MODULES.md) (сменные модули и протокол), [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) (схема и контракты блоков), [`docs/ASSUMPTIONS.md`](docs/ASSUMPTIONS.md) (все формулы и параметры).

## 2. Установка

Нужны **Git**, **uv** (менеджер Python) и интернет на время установки. Команды ниже работают и в PowerShell, и в обычной командной строке Windows (cmd); для macOS и Linux см. примечание в конце раздела.

**Шаг 1. Поставить Git и uv** (если ещё нет):

```powershell
winget install --id Git.Git -e
winget install --id astral-sh.uv -e
```

Закройте и откройте PowerShell заново, затем проверьте:

```powershell
git --version
uv --version
```

**Шаг 2. Скачать проект и поставить зависимости:**

```powershell
git clone -b external-stimulus https://github.com/WaRotiFY/speller1p.git
cd speller1p
uv python install 3.12
uv venv --python 3.12
uv pip install -e ".[test,eeg,external]"
```

`external` ставит `pylsl` и `pygame` для сменных модулей, `eeg` — чтение EDF.

`uv` сам скачает Python 3.12 и создаст изолированное окружение `.venv` в папке проекта. Активировать его не нужно: все команды ниже запускаются через `uv run --no-sync`.

Если Git недоступен, на GitHub переключитесь на ветку `external-stimulus`, скачайте **Code → Download ZIP**, распакуйте архив и откройте PowerShell в папке с `pyproject.toml`. Начните команды с `uv python install 3.12`.

**Шаг 3. Проверить, что всё стоит:**

```powershell
uv run --no-sync python -m pytest -q
```

Тесты должны завершиться без ошибок (`40 passed`). LSL-тесты пропускаются, если pylsl не установлен.

**macOS и Linux:** команды те же, кроме установки Git и uv (`brew install git uv` или [инструкция uv](https://docs.astral.sh/uv/getting-started/installation/)) и путей: вместо `configs\default.yaml` пишите `configs/default.yaml`.

## 3. Запуск со сменной программой стимуляции

В папке `speller1p` запустите спеллер с окном экспериментатора:

```powershell
uv run --no-sync python -m eeg_speller.external.server
```

**Окно PowerShell не закрывайте.** Откройте http://127.0.0.1:8770/. Настройка разбита на блоки по модулям схемы; выбор запоминается в браузере.

| Блок | Что выбирается |
|---|---|
| **0 сессия** | участник, задание (свободный набор, фраза из списка, своя); «с БЯМ / без БЯМ»; «показывать испытуемому целевую букву» — для copy-spelling и калибровки |
| **1 физиология** | программа стимуляции из `stimulus_kit/modules/` (модули физиологов) или `stimulus_kit/examples/`. Параметры модуля из его `settings.json` показаны полями (только на эту сессию). Галочки «пробел вместо ЭЭГ» и «в окне» |
| **2 клавиатура** | 6×6 по алфавиту, «как у Артёма» 4×11 с цифрами, ЙЦУКЕН 4×10 для набора или своя. Модуль получает её в каждой эпохе |
| **3 быстрая БЯМ** | **KenLM** — готовая словная n-грамма по имени на Hugging Face (по умолчанию `jonatasgrosman/wav2vec2-large-xlsr-53-russian`, 1,5 ГБ, скачивается один раз; нужен пакет `kenlm`, см. [`models/kenlm/README.md`](models/kenlm/README.md)) — лучшая на наших заданиях; **4-грамма** — своя буквенная, работает без скачивания; **HF** — любая нейросеть с Hugging Face по имени (`Qwen/Qwen2.5-0.5B`, нужен `pip install -e ".[hf]"`); mock |
| **4 статистический вывод** | модуль из папки `inference/` (`log_pool`, `linear_pool`, `tempered_bayes` или свой), его параметры, порог досрочной остановки |
| **5 медленная БЯМ** | выкл. / словарь (mock) / БЯМ по API: Ollama на этом компьютере, OpenRouter (бесплатные модели `:free`), Groq, NVIDIA NIM или свой адрес. Кнопка «список» загружает модели провайдера, ключ сохраняется только на этом компьютере. «Исправлять каждые N слов», окно W, «передавать варианты букв» (top-K апостериорных). Кнопка «промпт» открывает редактор с предпросмотром запроса |

Нажмите **«начать сессию»**. Выбранная программа откроется отдельным окном (с `--windowed` — в окне, иначе на весь экран и на мониторе из её настроек). С «пробелом вместо ЭЭГ»: щёлкните по окну программы и нажимайте пробел, когда нужная буква подсвечена или начинает двигаться.

Экран сессии:
- **сверху** — паспорт сессии;
- **по центру** — набираемый текст в стиле monkeytype: задание серым, верные буквы светлым, ошибки красным; под ним исправленный текст и кандидаты слов;
- **слева** — две таблички 2×2: топ-4 буквы после БЯМ (ЭЭГ + БЯМ) и до БЯМ (только ЭЭГ);
- **справа** — шкала уверенности с порогом остановки, номер эпохи, число стимулов, точность, скорость;
- **снизу** — история правок медленной БЯМ в виде чата: старые сообщения тускнеют, «показать всё» раскрывает её целиком.

Журнал эпох, модули и вывод программы стимуляции — в «подробнее».

**Облачная медленная БЯМ** отправляет набранный текст третьей стороне. Поэтому её можно запустить только с отдельной галочкой (Q-33, Q-41). Бесплатные ключи без карты: openrouter.ai/keys, console.groq.com/keys, build.nvidia.com. Лимиты у всех небольшие и часто меняются.

**Своя программа.** Положите `*.py` или папку с `main.py` (и, по желанию, `settings.json` и `module.json`) в `stimulus_kit/modules/` — она появится в списке после обновления страницы. Единственное правило: использовать `SpellerLink` из `speller_link.py`, копировать его не нужно. Контракт целиком — [`stimulus_kit/CONTRACT.md`](stimulus_kit/CONTRACT.md).

**Свой способ слияния БЯМ и ЭЭГ.** Положите `*.py` с `PARAMS` и `combine(prior, likelihood, params)` в `inference/` — см. [`inference/README.md`](inference/README.md).

**Запуск программы вручную.** В списке выберите «— запущу сам —», начните сессию и во втором окне PowerShell выполните, например:

```powershell
uv run --no-sync python stimulus_kit/examples/pygame_matrix.py --keyboard
```

**Всё одной командой** (спеллер в консоли и модуль сразу):

```powershell
uv run --no-sync python scripts/run_external_demo.py sim --text "привет"
uv run --no-sync python scripts/run_external_demo.py matrix --keyboard
```

**ЭЭГ из EDF через LSL.** Спеллер файл не открывает: его проигрывает отдельная утилита как живой усилитель, а отдельный декодер превращает сигнал в вероятности.

```powershell
uv run --no-sync python -m eeg_speller.physiology.edf_demo --text "привет"
uv run --no-sync python scripts/run_external_demo.py edf --profile configs/ext_no_llm.yaml
```

Первая команда создаёт синтетическую запись и обученный P300-декодер в `runs/edf_demo/`, вторая запускает спеллер, `stimulus_kit/decoders/p300_lsl_decoder.py` и `stimulus_kit/tools/edf_to_lsl.py`. Через минуту-полторы в консоли будет набранный текст.

**Реальный усилитель.** Нужен его LSL-поток и обученная модель P300 (калибровка — [`docs/PHYSIOLOGY.md`](docs/PHYSIOLOGY.md)), затем:

```powershell
uv run --no-sync python stimulus_kit/decoders/p300_lsl_decoder.py --eeg-name <имя LSL-потока> --model <модель.json>
```

Как писать свою программу стимуляции или свой декодер — [`stimulus_kit/README.md`](stimulus_kit/README.md). Протокол, проверки и ограничения — [`docs/EXTERNAL_MODULES.md`](docs/EXTERNAL_MODULES.md). Журналы сессий пишутся в `runs\external\`.

## 4. Браузерный режим со встроенной стимуляцией

Прежний режим из `main`: спеллер сам рисует матрицу в браузере. Сменные программы стимуляции в нём не используются.

Находясь в папке `speller1p`:

```powershell
uv run --no-sync python -m eeg_speller.web.server --port 8765 --output runs\gui
```

Сервер напечатает два адреса. **Окно PowerShell не закрывайте** — это работающий сервер; остановка — `Ctrl+C`.

| Окно | Адрес | Для кого |
|---|---|---|
| Экспериментатор | http://127.0.0.1:8765/operator | вы: настройки, запуск, живые распределения |
| Участник | http://127.0.0.1:8765/ | тот, кто набирает: матрица и текст |

Откройте окно экспериментатора и нажмите **«Открыть окно участника ↗»**. Если есть второй монитор или проектор — перетащите окно участника туда.

Если порт занят, замените `8765` на `8766` и в команде, и в адресах.

**Как набрать текст:**

1. В окне экспериментатора, в карточке «Сессия», введите ID участника (например, `P001`), выберите задание из списка или «Своя фраза…» и профиль `gui_slow.yaml`. Нажмите **«Начать сессию»**.
2. Щёлкните в окне участника: клавишу пробела принимает только оно.
3. Смотрите на нужную букву и **нажимайте пробел, только когда подсвечена её строка или её столбец**.
4. После серии вспышек система выберет букву. Клетка `⌫` удаляет последний символ, клетка `␣` вводит пробел в текст.

Во время набора окно экспериментатора показывает тепловые карты prior, правдоподобия и апостериорного распределения, решения детектора, слова-кандидаты и вызовы коррекции. Кнопки «Пауза» и «Стоп» управляют сессией, а режим «с БЯМ / без БЯМ» и другие параметры меняются в блоках под карточкой «Сессия». Журнал каждой сессии пишется в `runs\gui\`. Подробнее — [`docs/GUI.md`](docs/GUI.md).

## 5. Командная строка: симуляция, эксперименты, данные

Все команды запускаются из папки проекта. Точка входа — `eeg_speller/__main__.py`.

| Команда | Что делает | Время |
|---|---|---|
| `uv run --no-sync python -m eeg_speller run --config configs\default.yaml` | одна симулированная сессия **с БЯМ**: виртуальный участник набирает задание T001 | ~3 с |
| `uv run --no-sync python -m eeg_speller run --config configs\no_llm.yaml` | то же **без БЯМ** | ~3 с |
| `uv run --no-sync python -m eeg_speller run --config configs\default.yaml --verbose` | то же с выводом по каждому символу | ~3 с |
| `uv run --no-sync python -m eeg_speller experiment --config configs\compare_llm.yaml` | 10 виртуальных участников × 2 задания × 2 режима; среднее, дисперсия, 95 % ДИ, проверка порогов ТЗ | ~20 с |
| `uv run --no-sync python -m eeg_speller bench-llm --config configs\exp01.yaml` | качество быстрой модели: бит на символ, Top-N слов, задержка | ~1 с |
| `uv run --no-sync python -m eeg_speller replay runs\<сессия> --config configs\default.yaml` | прогнать записанную сессию заново: сигнал берётся из записи, языковая часть пересчитывается | ~3 с |
| `uv run --no-sync python -m eeg_speller export runs\<сессия>` | упаковать сессию в ZIP с проверкой целостности | ~1 с |

**Что выводит `run`.** В консоли — путь к сессии и метрики, например:

```
"symbol_accuracy": 0.875, "cer": 0.125, "speed_primary_cpm": 2.19, ...
```

- `symbol_accuracy` — доля верно выбранных символов;
- `cer` — доля ошибок по расстоянию Левенштейна;
- `speed_primary_cpm` — скорость, правильных символов в минуту (виртуальное время);
- `binary_flash_accuracy` / `binary_mean_accuracy` — точность target/non-target на одну вспышку и после усреднения повторений (две трактовки REQ-PERF-01).

**Что выводит `experiment`.** Сводку в консоли и файл `runs\compare_llm\summary.json`: метрики по режимам, прирост скорости с БЯМ с бутстреп-интервалом, p-значения и блок `threshold_checks` по каждому требованию ТЗ (в двух вариантах — по среднему и по нижней границе ДИ).

**Каталог сессии** (`runs\<session_id>\`):

```
session.json      манифест: ID, режимы, версии моделей, сид
config.yaml       полный снимок настроек
events.jsonl      журнал всех событий — первичный источник
texts\            target.txt, primary_final.txt, secondary_final.txt
tables\           epochs.csv, corrections.csv — производные таблицы
derived\          metrics.json, integrity.json
```

Формат описан в [`docs/DATA_MODEL.md`](docs/DATA_MODEL.md).

**Как менять настройки.** Скопируйте `configs\default.yaml` или создайте файл с `inherits: default.yaml` и перечислите только изменённые ключи. Главные переключатели:

| Ключ | Значения | Что меняет |
|---|---|---|
| `mode.llm` | `on` / `off` | с БЯМ или без |
| `task_id` | `T001`…`T040` | фраза из `data\tasks_ru.txt` |
| `physiology.sim.d_prime` | например `0.53`…`1.68` | качество симулированного сигнала |
| `epoch.n_repetitions` | целое | повторения вспышек за символ |
| `stimulus.flash_ms`, `isi_ms`, `pause_ms` | кратно 10 мс | тайминги |
| `stimulus.paradigm` | `row_column` / `single_symbol` | парадигма |
| `fusion.strategy`, `alpha`, `beta` | `log_pool` / `linear_pool` | способ слияния и веса |
| `detector.mode`, `tau` | `label` / `abstain` | поведение при неуверенности |
| `slow_llm.trigger`, `window_words` | `word_end`, … | когда и сколько исправлять |
| `runtime.max_symbols` | целое | обрезать задание для быстрой пробы |

Заготовки переборов для экспериментов — `configs\exp03.yaml`, `exp04.yaml`, `exp05.yaml`.

| Часть | Статус |
|---|---|
| Быстрая модель (prior по буквам), подсказки слов Top-N | работает на 5-граммной заглушке; интерфейс для настоящих БЯМ есть |
| Слияние (логарифмический и линейный пул), режим «без БЯМ» | реализовано |

| Медленная коррекция со скользящим окном | по умолчанию словарная заглушка; с профилем `gui_llm.yaml` — настоящая локальная БЯМ через Ollama (раздел 8) |
| Запись сессии, экспорт, replay, метрики и статистика | реализовано |
| Сменные программы стимуляции через LSL, досрочная остановка, показ результата | **реализовано**: протокол `speller-link@1`, примеры на pygame; на реальном мониторе и с фотодиодом не проверено |
| Упрощённое окно оператора для сменных модулей | реализовано |
| Браузерный интерфейс со встроенной стимуляцией (прежний режим) | реализовано |
| Декодер ЭЭГ | в новом режиме — **сменный модуль**; пример P300 из LSL проверен на синтетической EDF, физическое устройство ещё не проверено |
| Блок дообучения по исправленному тексту (RL) | **заглушка**: только рассылает псевдометки |
| Речевое воспроизведение (TTS), команды «сохранить/отправить» | **заглушка**: фиксирует время, звука нет |

Полная таблица «требование ТЗ → модуль → проверка» — [`docs/TRACEABILITY.md`](docs/TRACEABILITY.md).

## 8. Настоящая БЯМ для коррекции текста (Ollama)

По умолчанию медленную коррекцию выполняет словарная заглушка `mock_dictionary`. Её словарь мал, поэтому она часто не находит нужное слово. Вместо неё можно подключить **настоящую языковую модель**, которая работает на этом же компьютере через [Ollama](https://ollama.com). Интернет нужен только для её установки; текст участника никуда не отправляется: проект принимает только адреса `127.0.0.1`.

**Шаг 1. Установить Ollama и скачать модель** (один раз, около 2 ГБ):

```powershell
winget install --id Ollama.Ollama -e
ollama pull qwen2.5:3b
```

После установки Ollama работает в фоне (значок в трее). Если команда `ollama` не найдена, откройте новое окно PowerShell. Проверить, что модель отвечает:

```powershell
ollama run qwen2.5:3b "Исправь опечатку: привет, как у мебм дела"
```

**Шаг 2. Запустить сервер спеллера как обычно** (раздел 4, браузерный режим) и в окне экспериментатора выбрать профиль **`gui_llm.yaml`**. Он такой же, как `gui_slow.yaml`, но коррекцию делает модель `qwen2.5:3b`. Бэкенд, имя модели и адрес можно поменять и в блоке «Медленная БЯМ и коррекция».

После каждого завершённого слова модель получает последние 3 слова и предшествующий текст и возвращает исправленные слова. Результат появляется в строке «исправленный текст», а в окне экспериментатора видно каждый вызов «до → после» и его время. Если ответ модели не прошёл проверку (другое число слов, посторонние символы), исправление отбрасывается.

**Какую модель выбрать:**

| Модель | Размер | Скорость на обычном ноутбуке без видеокарты | Качество исправлений |
|---|---|---|---|
| `qwen2.5:1.5b` | ~1 ГБ | ~1–2 с на вызов | заметно слабее |
| `qwen2.5:3b` (по умолчанию) | ~2 ГБ | ~2–5 с на вызов | приемлемое |
| `qwen2.5:7b` | ~4,7 ГБ | ~5–15 с; быстро с видеокартой | лучше |

Пока модель думает, следующая попытка набора ждёт её ответа, поэтому на медленном компьютере берите `1.5b`. Другую модель скачайте командой `ollama pull <имя>` и впишите её имя в поле `model_id` или в `configs\gui_llm.yaml`.

**Если Ollama не запущен или модель не скачана,** сессия не начнётся, а окно экспериментатора покажет причину: `no LLM server` или `model … is not loaded`.

Вместо Ollama подойдёт любой локальный сервер с OpenAI-совместимым API, например `llama-server` из llama.cpp (`http://127.0.0.1:8080/v1`) или LM Studio (`http://127.0.0.1:1234/v1`): укажите адрес в поле «Адрес локального сервера». Промпт модели — `prompts\correction_local.txt`, код — `eeg_speller/llm/backends/local_openai.py`.

В режиме командной строки тот же бэкенд включается ключами конфига `slow_llm.backend: local_openai` и `slow_llm.model_id: qwen2.5:3b`.

## 9. Необязательно: кнопка «Предложить продолжение» (Qwen)

Добавляет в окно экспериментатора кнопку **«Предложить продолжение»**. В выборе букв Qwen не участвует. Для показа не нужен.

Нужны Visual Studio 2022 с компонентом **Desktop development with C++** и около 430 МБ места. В **Developer PowerShell for VS 2022**, из папки `speller1p`:

```powershell
New-Item -ItemType Directory -Force ..\speller-local\models | Out-Null
git clone https://github.com/ggml-org/llama.cpp.git ..\speller-local\llama.cpp
cmake -S ..\speller-local\llama.cpp -B ..\speller-local\llama.cpp\build-cpu -DLLAMA_BUILD_TESTS=OFF -DLLAMA_CURL=OFF -DGGML_CUDA=OFF -DGGML_VULKAN=OFF
cmake --build ..\speller-local\llama.cpp\build-cpu --config Release --target llama-cli -j 4
Invoke-WebRequest -Uri 'https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct-GGUF/resolve/main/qwen2.5-0.5b-instruct-q4_0.gguf' -OutFile '..\speller-local\models\qwen2.5-0.5b-instruct-q4_0.gguf'
```

Запуск сервера с моделью:

```powershell
$llamaCli = (Get-ChildItem ..\speller-local\llama.cpp\build-cpu -Filter llama-cli.exe -Recurse | Select-Object -First 1).FullName
uv run --no-sync python -m eeg_speller.web.server --port 8765 --output runs\gui --qwen-model ..\speller-local\models\qwen2.5-0.5b-instruct-q4_0.gguf --qwen-cli "$llamaCli"
```

Кнопка станет доступна после выбора хотя бы одного символа.

## 10. Если что-то не работает

| Симптом | Что сделать |
|---|---|
| `uv` или `git` «не является командой» | закрыть и заново открыть PowerShell после установки |
| Окно оператора: «ждём модуль стимуляции» | программа стимуляции не запущена или не нашла спеллер; запустить её во втором окне |
| Программа стимуляции: `speller control stream 'SpellerControl' not found` | сначала начать сессию в окне оператора, потом запускать программу |
| `ModuleNotFoundError: No module named 'pylsl'` или `'pygame'` | `uv pip install -e ".[test,eeg,external]"` |
| Эпоха не заканчивается | не запущен декодер: без `--keyboard` программе стимуляции нужен отдельный декодер ЭЭГ |
| Подключилась чужая сессия | в одной сети работают два спеллера; запускать на разных компьютерах вне общей сети или по очереди |
| Страница не открывается | проверить, что окно PowerShell с сервером открыто и в нём нет ошибки; адрес именно `127.0.0.1:8765` |
| `address already in use` | порт занят: запустить с `--port 8766` и открыть адреса с 8766 |
| Пробел не регистрируется | щёлкнуть в окне **участника** (не экспериментатора) и не оставлять курсор в текстовом поле |
| Буква не выбирается, попытка повторяется | это режим `abstain`: сигнала не хватило. Нажимать на обе вспышки — и строки, и столбца |
| «Начать сессию» не активна | сначала остановить текущую сессию кнопкой «Стоп»: одновременно идёт только одна |
| `ModuleNotFoundError: No module named 'yaml'` (или другой модуль) | зависимости не установились: выполнить `uv venv --python 3.12`, затем `uv pip install -e ".[test]"` — именно с двойными кавычками, одинарные в cmd не работают |
| `ModuleNotFoundError` (прочее) | выполнить `uv pip install -e ".[test]"` в папке проекта |
| `local_openai: no LLM server` | Ollama не запущен: запустить приложение Ollama или выполнить `ollama serve` |
| `local_openai: model … is not loaded` | модель не скачана: `ollama pull qwen2.5:3b` |
| Ошибка про `hf_causal` / `transformers` | выбран бэкенд настоящей модели; вернуть `mock_ngram` или выполнить `uv pip install -e ".[hf]"` |
