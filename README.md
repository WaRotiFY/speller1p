# EEG Speller: локальный прототип с интерфейсом в браузере

Этот репозиторий содержит исследовательский прототип ЭЭГ-спеллера. Он показывает матрицу букв, подсвечивает строки и столбцы и собирает текст из ответов пользователя. **Для демонстрации ответ ЭЭГ заменён нажатием пробела**: нажмите его, когда подсвеченная группа содержит задуманную букву. Шапка ЭЭГ не нужна. Интерфейс состоит из двух синхронных окон: в окне экспериментатора настраиваются экспериментальные блоки и видны распределения и предсказания, в окне участника идёт сам набор.

Ниже приведён полный путь от скачивания репозитория до первого набранного символа. Сервер работает только на `127.0.0.1`; данные сессий остаются на вашем компьютере. Базовый запуск не требует GPU, загрузки модели или подключения к внешнему API.

## 1. Что понадобится

- Windows 10/11, PowerShell и Git. Все команды ниже предназначены для PowerShell; открывать WSL не нужно. Если Git ещё не установлен, выполните `winget install --id Git.Git -e`.
- Интернет **при первой установке** Python и зависимостей. Сам базовый спеллер после установки работает офлайн.
- [`uv`](https://docs.astral.sh/uv/getting-started/installation/) для установки Python и создания отдельного окружения. Установите его через WinGet:

```powershell
winget install --id astral-sh.uv -e
```

Если `winget` недоступен, используйте [официальную инструкцию установки uv для Windows](https://docs.astral.sh/uv/getting-started/installation/). После установки откройте **новое окно PowerShell** и убедитесь, что команды работают:

```powershell
uv --version
git --version
```

Если PowerShell пишет, что команда не найдена, закройте и снова откройте его после установки.

## 2. Скачать проект и установить его через uv

Скопируйте и выполните команды по порядку:

```powershell
git clone https://github.com/Misterpin/speller1p.git
Set-Location speller1p
uv python install 3.12
uv venv --python 3.12
uv pip install -e .
```

Команда `uv venv` создаёт изолированную папку `.venv` внутри проекта. Активировать её вручную не нужно: `uv run` ниже использует её сам. Если репозиторий скачан ZIP-архивом вместо `git clone`, распакуйте его, откройте PowerShell в папке с `pyproject.toml` и начните с `uv python install 3.12`.

## 3. Запустить интерфейс

Оставаясь в папке `speller1p`, выполните:

```powershell
uv run --no-sync python -m eeg_speller.web.server --port 8765 --output runs\gui
```

В PowerShell появятся два адреса. Откройте **окно экспериментатора** [http://127.0.0.1:8765/operator](http://127.0.0.1:8765/operator) и нажмите в нём **«Открыть окно участника ↗»**. Откроется второе окно, [http://127.0.0.1:8765/](http://127.0.0.1:8765/), его удобно перенести на второй монитор перед участником. Окна синхронизированы: экспериментатор настраивает и запускает сессию, окно участника само начинает подсветку и отправляет нажатия.

Оставьте окно PowerShell с сервером открытым. Для остановки нажмите в нём `Ctrl+C`. Если порт 8765 занят, замените `8765` в команде и в адресах на другой свободный порт, например `8766`.

## 4. Первый набор: одна буква

1. В окне экспериментатора, в карточке «Сессия», введите ID участника (например, `P001`). В поле «Задание» выберите «Своя фраза…» и введите `а`. Базовый профиль оставьте **gui_slow.yaml**.
2. Нажмите **«Начать сессию»**. В окне участника над матрицей появится целевой символ `а`.
3. **Щёлкните в окне участника**: клавишу пробела принимает только оно. Смотрите на клетку `а`. **Нажмите и отпустите пробел, только когда подсвеченная строка или столбец содержит `а`.** В остальных случаях ничего не нажимайте.
4. За одну попытку каждая строка и каждый столбец появятся дважды в случайном порядке. Для `а` обычно нужны **четыре отдельных нажатия**: её строка и её столбец в каждом повторе. На медленном профиле попытка занимает около 20 секунд.
5. После последней вспышки декодер объединит нажатия с языковыми вероятностями. Если сигнала недостаточно, символ не добавится и попытка повторится. Когда `а` выбрана, сессия закончится сама.

Пока идут вспышки, окно экспериментатора показывает:
- три тепловые карты: prior быстрой модели, правдоподобие по нажатиям и апостериорное распределение после слияния; последние две пересчитываются после каждой вспышки;
- текущего лидера, его уверенность и порог детектора;
- слова-кандидаты, решения детектора, вызовы коррекции и журнал эпох.

Чтобы набрать **«привет»**, выберите задание «Своя фраза…» с этим словом или любое задание из списка. Если выбран неправильный символ, клетка `⌫` удаляет последнюю букву. Клетка `␣` вводит **настоящий пробел в текст**; клавиша пробела на клавиатуре только подаёт сигнал во время вспышки.

Кнопка **«Пауза»** останавливает набор после текущей попытки, **«Стоп»** завершает сессию досрочно. Журнал создаётся в `runs\gui\`; эта папка исключена из Git, поскольку в ней может быть набранный текст.

## 5. Экспериментальные блоки и модели

Ниже карточки «Сессия» расположены **экспериментальные блоки**, которые меняются между сессиями:
- режим «с БЯМ / без БЯМ» и парадигма предъявления;
- тайминги вспышек и число повторов;
- модель сигнала;
- быстрая БЯМ и её контекст;
- способ слияния и веса;
- детектор: порог, отказ, холодный старт;
- медленная БЯМ: момент запуска коррекции и окно.

Поля заполняются из выбранного `configs/gui_*.yaml`, изменённые помечаются точкой. Полный снимок настроек пишется в `config.yaml` каждой сессии. Удачное сочетание можно сохранить кнопкой «Сохранить как профиль»: появится новый `configs/gui_<имя>.yaml`. Подробнее — в [`docs/GUI.md`](docs/GUI.md).

- **Основной текст** — символы, выбранные декодером после каждой попытки.
- **Быстрый prior** в базовом профиле вычисляет локальная символьная 5-граммная модель `mock_ngram`. Она оценивает, какие буквы вероятны после уже набранного текста; затем декодер объединяет это с нажатиями пробела. Это статистическая заглушка, а не большая языковая модель.
- **Исправленный текст** ведётся отдельно. В базовом профиле его может менять словарная модель `mock_dictionary` после завершения слова и накопления контекста. Словарь ограничен встроенным корпусом, поэтому исправление может не произойти или испортить слово; окно экспериментатора показывает каждый вызов «до → после».
- **Локальный Qwen** необязателен. Если запустить сервер с моделью, в окне экспериментатора кнопка «Предложить продолжение» покажет короткую подсказку. Сейчас Qwen **не выбирает буквы и не исправляет текст автоматически**.

## 6. Необязательно: включить локальный Qwen

Этот раздел нужен только для кнопки продолжения текста. Базовый интерфейс из разделов 2–4 уже работает без Qwen. Модель весит около 429 МБ и скачивается **отдельно, вне репозитория**. Для CPU-сборки `llama.cpp` на Windows установите [Visual Studio 2022](https://visualstudio.microsoft.com/vs/community/) с компонентом **Desktop development with C++** согласно [инструкции `llama.cpp` для Windows](https://github.com/ggml-org/llama.cpp/blob/master/docs/build.md#build-with-cmake). Затем откройте **Developer PowerShell for VS 2022** и перейдите в папку `speller1p`.

```powershell
New-Item -ItemType Directory -Force ..\speller-local\models | Out-Null
git clone https://github.com/ggml-org/llama.cpp.git ..\speller-local\llama.cpp
cmake -S ..\speller-local\llama.cpp -B ..\speller-local\llama.cpp\build-cpu -DLLAMA_BUILD_TESTS=OFF -DLLAMA_CURL=OFF -DGGML_CUDA=OFF -DGGML_VULKAN=OFF
cmake --build ..\speller-local\llama.cpp\build-cpu --config Release --target llama-cli -j 4
Invoke-WebRequest -Uri 'https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct-GGUF/resolve/main/qwen2.5-0.5b-instruct-q4_0.gguf' -OutFile '..\speller-local\models\qwen2.5-0.5b-instruct-q4_0.gguf'
```

Остановите прежний сервер (`Ctrl+C`), найдите собранный `llama-cli.exe` и запустите сервер с двумя дополнительными аргументами:

```powershell
$llamaCli = (Get-ChildItem ..\speller-local\llama.cpp\build-cpu -Filter llama-cli.exe -Recurse | Select-Object -First 1).FullName
if (-not $llamaCli) { throw 'Не найден llama-cli.exe: проверьте сборку выше' }
uv run --no-sync python -m eeg_speller.web.server --port 8765 --output runs\gui --qwen-model ..\speller-local\models\qwen2.5-0.5b-instruct-q4_0.gguf --qwen-cli "$llamaCli"
```

Обновите окно экспериментатора. После выбора хотя бы одного символа станет доступна кнопка **«Предложить продолжение»**. Веса модели и `llama.cpp` лежат рядом с репозиторием, поэтому не попадут в коммит. Источник весов: [официальный репозиторий Qwen GGUF](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct-GGUF).

## 7. Проверка и другие команды

Для проверки кода установите тестовую зависимость и запустите тесты:

```powershell
uv pip install -e '.[test]'
uv run --no-sync python -m pytest -q
```

Остальные команды исследовательского прототипа:

```powershell
uv run --no-sync python -m eeg_speller run --config configs\default.yaml
uv run --no-sync python -m eeg_speller run --config configs\no_llm.yaml
uv run --no-sync python -m eeg_speller bench-llm --config configs\exp01.yaml
uv run --no-sync python -m eeg_speller experiment --config configs\compare_llm.yaml
```

Для `replay` и `export` подставьте реальный путь к созданной сессии вместо примера:

```powershell
$sessionPath = 'runs\ИМЯ_КАТАЛОГА_СЕССИИ'
uv run --no-sync python -m eeg_speller replay $sessionPath --config configs\default.yaml
uv run --no-sync python -m eeg_speller export $sessionPath
```

Параметры и допущения описаны в [`docs/ASSUMPTIONS.md`](docs/ASSUMPTIONS.md), состав записи — в [`docs/DATA_MODEL.md`](docs/DATA_MODEL.md), соответствие требованиям — в [`docs/TRACEABILITY.md`](docs/TRACEABILITY.md). Исходное ТЗ находится в [`input/TZ.md`](input/TZ.md). Подробнее о браузерном режиме — в [`docs/GUI.md`](docs/GUI.md).

Это **демонстрация без реальной ЭЭГ**. Она не подтверждает медицинскую применимость или показатели точности и скорости из ТЗ на участниках.
