# EEG Speller: прототип ЭЭГ-спеллера с языковой моделью

Исследовательский прототип P300-спеллера: на экране матрица 6×6 из русских букв, строки и столбцы по очереди подсвечиваются, а система по реакции человека и по подсказке языковой модели решает, какую букву он хотел набрать.

**Настоящей ЭЭГ здесь нет.** Физиологический модуль разрабатывает другая команда, поэтому сигнал мозга заменён:
- в **браузерном режиме** — нажатием клавиши пробела, когда подсвечена нужная буква;
- в **режиме командной строки** — симуляцией (виртуальный участник с заданным качеством сигнала).

Всё работает локально, без GPU, без интернета (после установки) и без внешних API.

## 1. Как это работает

Набор **одного символа** называется эпохой. В каждой эпохе происходит следующее:

```
 набранный текст ──► Быстрая модель ──► prior: какие буквы вероятны дальше
                                             │
 вспышки строк/столбцов ──► реакция ──► правдоподобие: на какой букве была реакция
 (Presentation Method)     (ЭЭГ / пробел /    │
                            симуляция)        ▼
                                    Слияние (Statistical Inference)
                                    posterior ∝ prior^α · правдоподобие^β
                                             │
                                             ▼
                                    Детектор: берёт самую вероятную букву
                                    (или повторяет эпоху, если не уверен)
                                             │
                                             ▼
                                    Первичный текст ──► (конец слова) ──► Медленная модель
                                                                          исправляет последние слова
                                                                                  │
                                                                                  ▼
                                                                          Исправленный текст
 Каждый шаг пишется в журнал сессии (events.jsonl).
```

Простыми словами:

1. **Быстрая модель** смотрит на уже набранный текст и говорит: «после „приве“ почти наверняка будет „т“». Это **prior** — 36 вероятностей, по одной на клетку.
2. **Вспышки.** За попытку каждая строка и каждый столбец матрицы подсвечиваются несколько раз (*повторения*). Реакция на вспышку, содержащую задуманную букву, — это сигнал P300 в ЭЭГ; здесь его роль играет пробел или симуляция. Из реакций получается **правдоподобие** для каждой буквы.
3. **Слияние** перемножает prior и правдоподобие (логарифмический пул) и получает **апостериорное распределение**. Поэтому даже при слабом сигнале языковая модель «дотягивает» правильную букву.
4. **Детектор** выбирает букву с максимальной вероятностью. Если уверенность ниже порога τ, он либо всё равно выбирает её с меткой «неуверенно» (режим `label`), либо повторяет попытку (режим `abstain`).
5. **Медленная модель** после каждого слова пробует исправить опечатки в последних словах. Её результат ведётся отдельной строкой — **исправленный текст**, первичный текст не меняется.
6. **Запись.** Все распределения, решения, тексты и тайминги пишутся в каталог сессии, поэтому любую сессию можно проанализировать и прогнать заново с другими настройками.

Режим **«без БЯМ»** — то же самое, но prior равномерный, а коррекция и подсказки слов выключены. Сравнение двух режимов на одних и тех же «участниках» — основа требования ТЗ о приросте скорости на 20 %.

Подробно: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) (схема и контракты блоков), [`docs/ASSUMPTIONS.md`](docs/ASSUMPTIONS.md) (все формулы и параметры).

## 2. Установка

Нужны **Git**, **uv** (менеджер Python) и интернет на время установки. Команды ниже — для Windows PowerShell; для macOS и Linux см. примечание в конце раздела.

**Шаг 1. Поставить Git и uv** (если ещё нет):

```powershell
winget install --id Git.Git -e
winget install --id astral-sh.uv -e
```

Закройте и откройте PowerShell заново, затем проверьте:

```powershell
git --version
uv --version
```

**Шаг 2. Скачать проект и поставить зависимости:**

```powershell
git clone -b operator-window https://github.com/WaRotiFY/speller1p.git
Set-Location speller1p
uv python install 3.12
uv venv --python 3.12
uv pip install -e '.[test]'
```

`uv` сам скачает Python 3.12 и создаст изолированное окружение `.venv` в папке проекта. Активировать его не нужно: все команды ниже запускаются через `uv run --no-sync`.

> Окно экспериментатора пока живёт в ветке `operator-window`, поэтому в `git clone` указан `-b operator-window`. После слияния в `main` этот флаг можно убрать.

**Шаг 3. Проверить, что всё стоит:**

```powershell
uv run --no-sync python -m pytest -q
```

Ожидаемый результат — `14 passed` примерно за 10 секунд.

**macOS и Linux:** команды те же, кроме установки Git и uv (`brew install git uv` или [инструкция uv](https://docs.astral.sh/uv/getting-started/installation/)) и путей: вместо `configs\default.yaml` пишите `configs/default.yaml`.

## 3. Запуск интерфейса в браузере

Находясь в папке `speller1p`:

```powershell
uv run --no-sync python -m eeg_speller.web.server --port 8765 --output runs\gui
```

Сервер напечатает два адреса. **Окно PowerShell не закрывайте** — это работающий сервер; остановка — `Ctrl+C`.

| Окно | Адрес | Для кого |
|---|---|---|
| Экспериментатор | http://127.0.0.1:8765/operator | вы: настройки, запуск, живые распределения |
| Участник | http://127.0.0.1:8765/ | тот, кто набирает: матрица и текст |

Откройте окно экспериментатора и нажмите **«Открыть окно участника ↗»**. Если есть второй монитор или проектор — перетащите окно участника туда.

Если порт занят, замените `8765` на `8766` и в команде, и в адресах.

## 4. Сценарий показа на 10 минут

### 4.1. Подготовка (до начала, 2 минуты)

1. Запустите сервер (раздел 3), откройте оба окна.
2. Сделайте один пробный набор буквы `а` (ниже), чтобы убедиться, что всё работает.

### 4.2. Набор одной буквы — показать принцип

1. В окне экспериментатора, карточка **«Сессия»**: ID участника `P001`, задание **«Своя фраза…»**, текст `а`. Профиль — **gui_slow.yaml** (медленные вспышки: 500 мс вспышка, 300 мс пауза, 2 повторения).
2. Нажмите **«Начать сессию»**.
3. **Щёлкните в окне участника** — пробел принимает только оно.
4. Смотрите на клетку `а`. **Нажимайте пробел, только когда подсвечена её строка или её столбец.** Обычно это 4 нажатия за попытку (~20 секунд).
5. Когда буква выбрана, сессия закроется сама.

Пока идут вспышки, покажите в окне экспериментатора:
- **три тепловые карты**: prior (что ожидает модель), правдоподобие (что «сказали» нажатия), апостериорное (их произведение). Последние две меняются после каждой вспышки;
- **лидера и порог τ**: видно, когда система «уверилась»;
- **журнал эпох**: вероятность цели до и после слияния — это и есть вклад языковой модели.

### 4.3. Набор слова — показать вклад языковой модели

1. Своя фраза `привет` (или задание из списка), тот же профиль.
2. На первых буквах prior почти равномерный, а к `приве_` модель уже уверенно ждёт `т` — видно на карте prior. Нажатия можно делать менее аккуратно: слияние вытянет правильную букву.
3. Если выбрана не та буква — клетка `⌫` удаляет последний символ. Клетка `␣` вводит пробел в текст (а клавиша пробела — это только «сигнал»).

### 4.4. С БЯМ и без БЯМ

Перед следующей сессией в блоке **«Режим и парадигма»** переключите режим на «без БЯМ» и наберите то же слово. Карта prior станет ровной, решение держится только на нажатиях — чаще нужны повторы попыток.

### 4.5. Что показать в данных

Откройте папку `runs\gui\<сессия>\`: там `config.yaml` (снимок всех настроек), `events.jsonl` (каждое событие с меткой времени), `texts\` (цель, первичный и исправленный текст), `tables\epochs.csv` (строка на каждую эпоху с тремя распределениями). Из этого считаются все метрики ТЗ.

### 4.6. Что честно сказать, если спросят

- **Это не ЭЭГ.** Пробел — контролируемая имитация реакции P300. Контракт для настоящего модуля физиологии описан, подключение — следующая итерация (`physiology/stub_live.py`).
- **Языковые модели — пока заглушки.** Быстрая — символьная 5-граммная модель, медленная — словарная коррекция. Обе работают без GPU. Интерфейс для настоящих БЯМ (`hf_causal`, `openai_compat`) есть; выбор конкретной модели — эксперимент EXP-01/EXP-02.
- **Медленная заглушка может испортить слово** (словарь маленький). Поэтому исправленный текст ведётся отдельно и каждый вызов виден как «до → после».
- **Числа из симуляции не проверяют требования ТЗ.** Например, при 10 повторениях из ТЗ скорость упирается примерно в 2 символа в минуту — это конфликт требований, разобранный в `docs/OPEN_QUESTIONS.md` (Q-04).

## 5. Командная строка: симуляция, эксперименты, данные

Все команды запускаются из папки проекта. Точка входа — `eeg_speller/__main__.py`.

| Команда | Что делает | Время |
|---|---|---|
| `uv run --no-sync python -m eeg_speller run --config configs\default.yaml` | одна симулированная сессия **с БЯМ**: виртуальный участник набирает задание T001 | ~3 с |
| `uv run --no-sync python -m eeg_speller run --config configs\no_llm.yaml` | то же **без БЯМ** | ~3 с |
| `uv run --no-sync python -m eeg_speller run --config configs\default.yaml --verbose` | то же с выводом по каждому символу | ~3 с |
| `uv run --no-sync python -m eeg_speller experiment --config configs\compare_llm.yaml` | 10 виртуальных участников × 2 задания × 2 режима; среднее, дисперсия, 95 % ДИ, проверка порогов ТЗ | ~20 с |
| `uv run --no-sync python -m eeg_speller bench-llm --config configs\exp01.yaml` | качество быстрой модели: бит на символ, Top-N слов, задержка | ~1 с |
| `uv run --no-sync python -m eeg_speller replay runs\<сессия> --config configs\default.yaml` | прогнать записанную сессию заново: сигнал берётся из записи, языковая часть пересчитывается | ~3 с |
| `uv run --no-sync python -m eeg_speller export runs\<сессия>` | упаковать сессию в ZIP с проверкой целостности | ~1 с |

**Что выводит `run`.** В консоли — путь к сессии и метрики, например:

```
"symbol_accuracy": 0.875, "cer": 0.125, "speed_primary_cpm": 2.19, ...
```

- `symbol_accuracy` — доля верно выбранных символов;
- `cer` — доля ошибок по расстоянию Левенштейна;
- `speed_primary_cpm` — скорость, правильных символов в минуту (виртуальное время);
- `binary_flash_accuracy` / `binary_mean_accuracy` — точность target/non-target на одну вспышку и после усреднения повторений (две трактовки REQ-PERF-01).

**Что выводит `experiment`.** Сводку в консоли и файл `runs\compare_llm\summary.json`: метрики по режимам, прирост скорости с БЯМ с бутстреп-интервалом, p-значения и блок `threshold_checks` по каждому требованию ТЗ (в двух вариантах — по среднему и по нижней границе ДИ).

**Каталог сессии** (`runs\<session_id>\`):

```
session.json      манифест: ID, режимы, версии моделей, сид
config.yaml       полный снимок настроек
events.jsonl      журнал всех событий — первичный источник
texts\            target.txt, primary_final.txt, secondary_final.txt
tables\           epochs.csv, corrections.csv — производные таблицы
derived\          metrics.json, integrity.json
```

Формат описан в [`docs/DATA_MODEL.md`](docs/DATA_MODEL.md).

**Как менять настройки.** Скопируйте `configs\default.yaml` или создайте файл с `inherits: default.yaml` и перечислите только изменённые ключи. Главные переключатели:

| Ключ | Значения | Что меняет |
|---|---|---|
| `mode.llm` | `on` / `off` | с БЯМ или без |
| `task_id` | `T001`…`T040` | фраза из `data\tasks_ru.txt` |
| `physiology.sim.d_prime` | например `0.53`…`1.68` | качество симулированного сигнала |
| `epoch.n_repetitions` | целое | повторения вспышек за символ |
| `stimulus.flash_ms`, `isi_ms`, `pause_ms` | кратно 10 мс | тайминги |
| `stimulus.paradigm` | `row_column` / `single_symbol` | парадигма |
| `fusion.strategy`, `alpha`, `beta` | `log_pool` / `linear_pool` | способ слияния и веса |
| `detector.mode`, `tau` | `label` / `abstain` | поведение при неуверенности |
| `slow_llm.trigger`, `window_words` | `word_end`, … | когда и сколько исправлять |
| `runtime.max_symbols` | целое | обрезать задание для быстрой пробы |

Заготовки переборов для экспериментов — `configs\exp03.yaml`, `exp04.yaml`, `exp05.yaml`.

## 6. Что реализовано, а что заглушка

| Часть | Статус |
|---|---|
| Быстрая модель (prior по буквам), подсказки слов Top-N | работает на 5-граммной заглушке; интерфейс для настоящих БЯМ есть |
| Слияние (логарифмический и линейный пул), режим «без БЯМ» | реализовано |
| Детектор с порогом, повтором попытки, меткой холодного старта | реализовано |
| Медленная коррекция со скользящим окном | работает на словарной заглушке; интерфейс для настоящих БЯМ есть |
| Запись сессии, экспорт, replay, метрики и статистика | реализовано |
| Браузерный интерфейс: окно участника и окно экспериментатора | реализовано |
| Физиологический модуль (ЭЭГ) | **заглушка**: симуляция или пробел |
| Блок дообучения по исправленному тексту (RL) | **заглушка**: только рассылает псевдометки |
| Речевое воспроизведение (TTS), команды «сохранить/отправить» | **заглушка**: фиксирует время, звука нет |

Полная таблица «требование ТЗ → модуль → проверка» — [`docs/TRACEABILITY.md`](docs/TRACEABILITY.md).

## 7. Где что лежит в коде

```
eeg_speller/
  __main__.py      точка входа командной строки (run, experiment, replay, export, bench-llm)
  epoch/loop.py    ГЛАВНЫЙ ЦИКЛ: EpochRunner — prior → физиология → слияние → решение → коррекция → запись
  epoch/fusion.py  слияние prior и физиологии
  llm/             быстрая и медленная модели и их бэкенды (mock, hf_causal, openai_compat)
  physiology/      контракт модуля физиологии и симуляция
  decoding/        детектор символа
  text/            первичный и исправленный текст
  recording/       журнал событий, хранение, экспорт, replay
  evaluation/      метрики, статистика, эксперименты
  web/             сервер и страницы браузерного режима
configs/           профили запуска (default, no_llm, gui_slow, gui_medium, exp*)
data/              задания tasks_ru.txt и корпус для заглушек
docs/              архитектура, допущения, открытые вопросы, модель данных
```

Если разбираться с нуля, начинайте с `eeg_speller/epoch/loop.py`. В коде решения помечены `# ASSUMPTION[MA-NN]` (математическое допущение из `docs/ASSUMPTIONS.md`) и `# STUB[Q-NN]` / `# IMPROV[Q-NN]` (временное решение по открытому вопросу из `docs/OPEN_QUESTIONS.md`). Сверка пометок с документами: `uv run --no-sync python scripts\check_markers.py`.

## 8. Необязательно: локальный Qwen

Добавляет в окно экспериментатора кнопку **«Предложить продолжение»**. В выборе букв Qwen не участвует. Для показа не нужен.

Нужны Visual Studio 2022 с компонентом **Desktop development with C++** и около 430 МБ места. В **Developer PowerShell for VS 2022**, из папки `speller1p`:

```powershell
New-Item -ItemType Directory -Force ..\speller-local\models | Out-Null
git clone https://github.com/ggml-org/llama.cpp.git ..\speller-local\llama.cpp
cmake -S ..\speller-local\llama.cpp -B ..\speller-local\llama.cpp\build-cpu -DLLAMA_BUILD_TESTS=OFF -DLLAMA_CURL=OFF -DGGML_CUDA=OFF -DGGML_VULKAN=OFF
cmake --build ..\speller-local\llama.cpp\build-cpu --config Release --target llama-cli -j 4
Invoke-WebRequest -Uri 'https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct-GGUF/resolve/main/qwen2.5-0.5b-instruct-q4_0.gguf' -OutFile '..\speller-local\models\qwen2.5-0.5b-instruct-q4_0.gguf'
```

Запуск сервера с моделью:

```powershell
$llamaCli = (Get-ChildItem ..\speller-local\llama.cpp\build-cpu -Filter llama-cli.exe -Recurse | Select-Object -First 1).FullName
uv run --no-sync python -m eeg_speller.web.server --port 8765 --output runs\gui --qwen-model ..\speller-local\models\qwen2.5-0.5b-instruct-q4_0.gguf --qwen-cli "$llamaCli"
```

Кнопка станет доступна после выбора хотя бы одного символа.

## 9. Если что-то не работает

| Симптом | Что сделать |
|---|---|
| `uv` или `git` «не является командой» | закрыть и заново открыть PowerShell после установки |
| Страница не открывается | проверить, что окно PowerShell с сервером открыто и в нём нет ошибки; адрес именно `127.0.0.1:8765` |
| `address already in use` | порт занят: запустить с `--port 8766` и открыть адреса с 8766 |
| Пробел не регистрируется | щёлкнуть в окне **участника** (не экспериментатора) и не оставлять курсор в текстовом поле |
| Буква не выбирается, попытка повторяется | это режим `abstain`: сигнала не хватило. Нажимать на обе вспышки — и строки, и столбца |
| «Начать сессию» не активна | сначала остановить текущую сессию кнопкой «Стоп»: одновременно идёт только одна |
| `ModuleNotFoundError` | выполнить `uv pip install -e '.[test]'` в папке проекта |
| Ошибка про `hf_causal` / `transformers` | выбран бэкенд настоящей модели; вернуть `mock_ngram` или выполнить `uv pip install -e '.[hf]'` |
