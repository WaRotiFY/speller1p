# Модули стимуляции и декодирования для спеллера

Эта папка — всё, что нужно физиологам, чтобы подключить свою программу к спеллеру. Спеллер не рисует экран испытуемого и не знает, что на нём происходит. Он только говорит «начинаем выбирать символ», принимает вероятности букв и сообщает выбранный символ.

## Одно обязательное правило

Скопируйте `speller_link.py` рядом со своей программой (нужен только `pip install pylsl`) и сразу после каждого `flip` сообщайте, какие символы сейчас подсвечены:

```python
from speller_link import SpellerLink

link = SpellerLink()                      # находит запущенный спеллер

# ... ваш код pygame ...
pygame.display.flip()
link.flash(["а", "б", "в", "г", "д", "е"])  # сразу после flip
```

Больше ничего не обязательно. Как выглядит стимуляция, сколько повторений, какой порядок — решаете вы.

## Необязательные вызовы

| Вызов | Зачем |
|---|---|
| `epoch = link.wait_epoch()` | Ждать, пока спеллер попросит следующий символ. В `epoch` есть `symbols` (36 символов), `rows()` (по строкам матрицы 6×6), `text` (уже набранный текст), `settings` (рекомендуемые `flash_ms`, `isi_ms`, `n_repetitions` — можно игнорировать). Возвращает `None`, когда сессия закончилась. |
| `link.should_stop()` | `True`, когда спеллер уже уверен в символе: можно прекратить вспышки и перейти к следующему. Если не проверять — ничего не сломается, просто эпоха будет дольше. |
| `link.done()` | Вы закончили показ этой эпохи. Помогает спеллеру не ждать лишнего. |
| `link.result()` / `link.wait_result()` | Какой символ выбран и весь набранный текст — чтобы показать испытуемому между эпохами. |
| `link.paused`, `link.ended` | Оператор поставил паузу / завершил сессию. |
| `link.send_likelihood(p, final=...)` | Если ваша программа сама декодирует ЭЭГ (см. ниже). |

Типичный цикл:

```python
while (epoch := link.wait_epoch()) is not None:
    for rep in range(10):
        for group in my_shuffled_groups(epoch.rows()):
            draw(group); pygame.display.flip()
            link.flash(group)
            ...
            if link.should_stop():
                break
    link.done()
    show(link.wait_result())
```

## Декодер: кто превращает ЭЭГ в вероятности

В этой ветке вероятности букв присылают физиологи. Это может быть та же программа, что рисует, или отдельная — спеллеру всё равно.

```python
link = SpellerLink(name="my_decoder", role="decoder")
link.send_likelihood({"а": 0.02, "б": 0.61, ...}, epoch=epoch_id)          # промежуточная оценка
link.send_likelihood({...}, epoch=epoch_id, final=True)                     # окончательная
```

Правила для значений:
- это **P(ЭЭГ | задуман символ)** — без языковой модели и частот букв: языковую модель спеллер добавит сам, иначе она будет учтена дважды;
- нормировать не обязательно; символы, которых нет в словаре, делят оставшуюся массу поровну;
- можно слать обновление после каждой вспышки — тогда спеллер сможет остановить эпоху досрочно;
- `usable=False` — данные плохие (артефакт, обрыв); спеллер не будет выбирать символ и повторит эпоху.

## Сигнал завершения демонстрации

Спеллер после каждого обновления складывает вероятности от декодера с подсказкой языковой модели. Когда уверенность в лучшем символе достигает порога (`external.stop_confidence` в профиле, по умолчанию 0,99, и не раньше 12 обновлений), он присылает `stop`, и `link.should_stop()` становится `True`. После этого спеллер ждёт окончательную оценку (`final=True`) не дольше `stop_grace_s` и выбирает символ. Профиль `ext_no_stop.yaml` отключает этот сигнал.

## Примеры (можно менять местами)

| Файл | Что делает |
|---|---|
| `examples/pygame_matrix.py` | Матрица 6×6, мигают строки и столбцы. `--keyboard`: пробел вместо ЭЭГ. `--photodiode`: белый квадрат в углу для фотодиода. |
| `examples/pygame_rsvp.py` | Совсем другая картинка: по одной букве в центре экрана. Спеллер разницы не замечает. |
| `examples/headless_sim.py` | Без экрана: симулированные вспышки и «мозг» с заданным качеством сигнала `--d-prime`. Для проверки на любом компьютере. |
| `decoders/p300_lsl_decoder.py` | Отдельный процесс-декодер: P300 из любого LSL-потока ЭЭГ. Пример того, как может выглядеть декодер физиологов. |
| `tools/edf_to_lsl.py` | Проигрывает EDF-запись в LSL как живой усилитель (ЭЭГ + записанные вспышки). Спеллер сам EDF не открывает. |

## Как запустить

Положите свою программу в `stimulus_kit/modules/`. Запустите окно экспериментатора:

```powershell
uv run --no-sync python -m eeg_speller.external.server
```

Откройте `http://127.0.0.1:8770/`, выберите программу в списке «Программа стимуляции» и нажмите «Начать сессию». Спеллер сам запустит её и закроет по «Завершить». `speller_link` при таком запуске импортируется без копирования. Вывод программы пишется в `runs/external/<сессия>/external/stimulus.log`.

Можно запускать и вручную: выберите «— запущу сам —» и запустите программу из терминала.

Всё одной командой (спеллер в консоли + модули):

```powershell
uv run --no-sync python scripts/run_external_demo.py sim --text "привет"
uv run --no-sync python scripts/run_external_demo.py matrix --keyboard
uv run --no-sync python -m eeg_speller.physiology.edf_demo --text "привет"
uv run --no-sync python scripts/run_external_demo.py edf --profile configs/ext_no_llm.yaml
```

Нужен `pip install pylsl pygame` (или `uv pip install -e ".[external]"`).

## Если программа не на Python

Протокол — три LSL-потока маркеров со строками JSON (`speller-link@1`). Их можно слать из PsychoPy, MATLAB, C# и т. п.

| Поток (name) | Кто шлёт | Сообщения |
|---|---|---|
| `SpellerControl` | спеллер | `{"cmd":"epoch_start","epoch":3,"symbols":[...36],"layout":[6,6],"text":"при","settings":{...}}`, `{"cmd":"stop","epoch":3}`, `{"cmd":"result","epoch":3,"symbol":"в","text":"прив"}`, `{"cmd":"pause"}`, `{"cmd":"resume"}`, `{"cmd":"end"}` |
| `SpellerStimuli` | стимуляция | `{"epoch":3,"flash":["а","б"]}` — **метка времени LSL = момент flip**; `{"epoch":3,"event":"done"}` |
| `SpellerLikelihood` | декодер | `{"epoch":3,"p":{"а":0.1,...},"final":false,"usable":true}` |

## Точность времени

Метку вспышки ставит та же программа, что рисует, в момент `flip`, в часах LSL. По сети LSL передаёт её вместе с меткой времени и пересчитывает в часы приёмника, поэтому задержка доставки на точность не влияет (на одном компьютере расхождение в тестах — менее 1 мс). Остаётся задержка монитора: между `flip` и реальным свечением проходит постоянное время (обычно 1 кадр и больше). Его один раз измеряют фотодиодом (`--photodiode`) и вычитают, передавая исправленное время в `link.flash(group, timestamp=...)`.
