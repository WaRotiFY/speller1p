# Модули стимуляции

Окно оператора показывает в списке «программа стимуляции» всё, что лежит в этой папке и использует `SpellerLink`:

- **файл `*.py`** — название берётся из первой строки docstring;
- **папка с `main.py`**. Рядом можно положить:
  - `settings.json` — параметры станут полями ввода в окне оператора;
  - `module.json` — `label` (название), `description` (одна строка о модуле) и `help` (подсказка к каждому параметру).

| Папка | Стимул |
|---|---|
| `flash_rows_cols/` | вспышки строк и столбцов |
| `moving_letters/` | короткое движение буквы в случайный момент |
| `moving_circles/` | кружок буквы пробегает по эллипсу |

Копировать `speller_link.py` и `module_tools.py` не нужно: окно оператора подставляет путь само.

Модуль запускается в папке сессии, его вывод пишется в `runs/external/<сессия>/external/stimulus.log`. Последние строки этого лога видны в окне оператора.
