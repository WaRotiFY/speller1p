# Сюда кладите свои программы стимуляции

Программа появится в окне экспериментатора в списке «программа стимуляции», если это:

- **файл `*.py`**, в котором используется `SpellerLink`; название — первая строка docstring;
- **папка с `main.py`**, который использует `SpellerLink`. В папке можно положить `settings.json` — параметры станут полями в окне оператора — и `module.json` с `label` (название) и `help` (подсказка к каждому параметру).

Готовые модули здесь:

| Папка | Парадигма |
|---|---|
| `flash_rows_cols/` | мигание строк и столбцов, параметры — по описанию физиологов |
| `artem_moving_letters/` | движение букв, Paradigm_0/0.0 Артёма |
| `artem_circles/` | кружки по эллипсам, Paradigm_0/0.4 Артёма |

Копировать `speller_link.py` и `module_tools.py` не нужно: спеллер подставляет путь сам. Программа запускается в папке сессии, её вывод — в `runs/external/<сессия>/external/stimulus.log`, последние строки видны в окне экспериментатора.
