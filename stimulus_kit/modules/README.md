# Модули стимуляции

Окно оператора показывает в списке модулей блока «физиология» всё, что лежит в этой папке и использует `SpellerLink`:

- **файл `*.py`** — название берётся из первой строки docstring;
- **папка с `main.py`**. Рядом можно положить:
  - `settings.json` — все параметры модуля: клавиатура (`alphabet`, `num_rows`, `num_cols`), фраза для подсказки цели (`sentence`), пробел вместо ЭЭГ, полный экран, времена и цвета;
  - `module.json` — `label` (название), `description` (одна строка о модуле) и `help` (пояснение к каждому ключу `settings.json`).

Оператор только выбирает модуль. Чтобы изменить параметры, правьте `settings.json` модуля.

| Папка | Стимул |
|---|---|
| `flash_rows_cols/` | вспышки строк и столбцов |
| `moving_letters/` | короткое движение буквы в случайный момент |
| `moving_circles/` | кружок буквы пробегает по эллипсу |
| `simulator/` | без экрана: виртуальный испытуемый и симулированная ЭЭГ, для проверки цепочки |

Копировать `speller_link.py` и `module_tools.py` не нужно: окно оператора подставляет путь само.

Модуль запускается в папке сессии, его вывод пишется в `runs/external/<сессия>/external/stimulus.log`. Если модуль завершился с ошибкой, последние строки этого лога появятся в окне оператора.
