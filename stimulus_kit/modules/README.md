# Сюда кладите свои программы стимуляции

Любой файл `*.py` из этой папки, в котором используется `SpellerLink`, появится в окне экспериментатора в списке «Программа стимуляции». Первая строка docstring файла — его название в списке.

```python
"""Мои круги на экране (pygame)."""
from speller_link import SpellerLink   # копировать speller_link.py не нужно, спеллер подставит путь сам
link = SpellerLink()
...
pygame.display.flip()
link.flash(["а", "б"])
```

Если программа понимает ключ `--keyboard`, в окне появится галочка «Пробел вместо ЭЭГ». Если программа принимает `--text`, ей передаётся фраза задания. Другие ключи можно вписать в поле «Доп. аргументы программы».

Вывод программы (print и ошибки) пишется в `runs/external/<сессия>/external/stimulus.log`; последние строки видны в окне экспериментатора, если программа упала.

Подробнее о правилах — [`../README.md`](../README.md).
