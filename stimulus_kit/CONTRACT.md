# Контракт физиологии — `speller-link@2`

Модуль стимуляции рисует экран и сообщает фактические стимулы. Декодер читает ЭЭГ
и оценивает реакции. Это могут быть одна или две отдельные программы. Спеллер
объединяет свидетельства ЭЭГ с быстрым prior и отдельно выполняет медленную коррекцию текста.
Сообщения — JSON в трёх LSL-потоках типа Markers (один строковый канал).

**Эпоха** — попытка выбора одного символа. **Trial** — полный цикл стимуляции для
каждого символа по правилам парадигмы. Для матрицы — предъявление всех строк И всех
столбцов; для движущихся букв/кружков — по одному полному движению каждого символа;
для RSVP — по одному предъявлению каждого символа. Незавершённый цикл не считается trial.

## 1. Клавиатура проверяется перед КАЖДОЙ эпохой

1. Спеллер посылает в `SpellerControl` сообщение `epoch_prepare`, содержащее
   `epoch`, `session_id`, предлагаемые `symbols`, `layout`.
2. Стимуляция отвечает в `SpellerStimuli`: `event=keyboard`, те же `epoch` и
   `session_id`, свой актуальный список `symbols` и `layout`.
3. Спеллер проверяет набор, порядок и раскладку, рассчитывает prior и отправляет
   `epoch_start` с зафиксированной клавиатурой и её `keyboard_id`.

До успешного ответа стимуляция не начинается. Таймаут ставит сеанс на паузу и
отображается оператору. Клавиатура неизменна внутри эпохи; изменение применяется
при следующей сверке. Старые ответы с другим номером эпохи/сеанса не подтверждают готовность.

`SpellerLink(keyboard=..., layout=...)` автоматически отвечает на `epoch_prepare`
значением `link.keyboard`. Если модуль меняет раскладку, он обновляет этот словарь
до следующей эпохи. Декодер с `role="decoder"` не объявляет клавиатуру.
Старые независимые модули нужно обновить до v2; для явно обозначенного legacy-профиля
есть `external.keyboard_check_each_epoch: false`, без гарантии сверки на каждой эпохе.

## 2. Предъявление и метки времени

```python
from speller_link import SpellerLink
link = SpellerLink(name="my_module", keyboard=list("АБВГ"), layout=(2, 2))
epoch = link.wait_epoch()
# epoch.id, epoch.symbols, epoch.layout, epoch.text, epoch.settings, epoch.keyboard_id
pygame.display.flip()
link.flash(["А", "Б"])  # СРАЗУ после flip; timestamp можно задать явно в часах LSL
```

`flash` содержит `epoch`, `flash_id` (от 1 внутри эпохи), `keyboard_id` и `flash` —
список реально стимулированных символов. LSL-метка — время появления стимула,
а не время доставки. Задержку монитора проверяют фотодиодом и учитывают в timestamp.
Нельзя переносить распределение на новую клавиатуру только по индексам массива.

Цель задания спеллер модулю не сообщает. Для copy-spelling модуль сам показывает
подсказку из своего `settings.json`; декодер при обычном вводе правильного ответа не получает.
Каналы, фильтры и классификатор — настройки декодера, а не рисующей программы.

## 3. Правдоподобия ЭЭГ: декодер → спеллер

Поток `SpellerLikelihood`:

```python
link.send_likelihood({"А": .7, "Б": .1, "В": .1, "Г": .1},
                     through_flash=4, usable=True, final=False)
```

Это **P(ЭЭГ | символ)** без языкового prior. Нормировать не обязательно. Обновление
содержит накопленные свидетельства эпохи, а не приращение. `through_flash` — номер
последнего стимула в непрерывном обработанном префиксе (включая отвергнутые окна).
У синхронного встроенного декодера он заполняется автоматически числом `link.flash`.
Асинхронный/отдельный декодер обязан указать фактически обработанный номер.
`usable=False` означает отсутствие пригодных данных, а не отрицательную оценку целевой реакции.
После последней оценки — `final=True`.
Рисующая программа обязательно посылает `link.done()` после всех своих меток
`trial_done`. Эти метки идут по одному упорядоченному потоку; спеллер v2 ждёт
`done`, даже если финальное правдоподобие пришло раньше по другому LSL-потоку.

## 4. Полное распределение после каждого trial: спеллер → модуль

После полного цикла модуль вызывает `link.trial_done()`. Сообщение `trial_done`
содержит `epoch`, `trial` (от 1), `through_flash` (последний стимул цикла), `keyboard_id`.
Спеллер ждёт, пока декодер обработает эти стимулы, и отправляет `cmd=distribution`
в `SpellerControl`. Он НЕ возвращает старое распределение, если последняя реакция ещё не готова.

Ответ содержит:

| Поле | Значение |
|---|---|
| `session_id`, `epoch`, `trial`, `keyboard_id` | Однозначная привязка к сеансу, эпохе, циклу и клавиатуре |
| `semantics` | `posterior`: результат слияния ЭЭГ и быстрого prior |
| `symbols`, `p` | Полный упорядоченный набор символов и нормированный массив вероятностей |
| `trial_last_flash`, `through_flash` | Граница trial и граница фактически использованной ЭЭГ; последняя может быть больше при пакетной обработке |
| `update`, `lsl_s`, `fusion`, `usable` | Номер обновления, время, метод слияния, пригодность данных |

```python
trial = link.trial_done()
# Когда ответ пришёл:
snapshot = link.get_distribution(trial=trial)  # None, пока ответ не готов
# Без trial — последний ГОТОВЫЙ trial текущей эпохи; номер всегда есть в snapshot.
# Повторить запрос сохранённого результата:
link.request_distribution(trial=trial)
```

Снимок возвращается копией. После начала новой эпохи старые снимки очищаются.
Результат НЕ содержит медленной посткоррекции и НЕ может возвращаться в
`send_likelihood`: иначе языковый prior и свидетельства будут учтены повторно.

## 5. Два разных вида остановки

**Автоматический stop:** спеллер достиг порога уверенности. `link.should_stop()`
становится True. Модуль завершает предъявления, присылает последнюю оценку ЭЭГ и
`done`; спеллер принимает решение и отправляет `result`.

**Отмена эпохи пользователем:** модуль вызывает `link.user_stop()`.
Спеллер немедленно отменяет эпоху: не ждёт оставшихся оценок, НЕ выбирает и НЕ
добавляет символ. Посылает `epoch_cancelled` и `result` с `symbol=null`,
`reason=user_stop`, затем `pause`. Запоздавшие оценки отменённой эпохи не применяются.
Цель и текст сохраняются. После «продолжить» начинается новая эпоха с новым id и
новой сверкой клавиатуры. В готовых pygame-модулях Esc отменяет эпоху.
`link.epoch_cancelled()` отличает отмену от автоматического stop.

**Завершение сеанса:** отдельная команда `end`. Это не то же самое, что отмена эпохи.

## 6. Потоки и минимальный цикл

| Поток | Направление | Сообщения |
|---|---|---|
| `SpellerControl` | спеллер → модули | `epoch_prepare`, `epoch_start`, `distribution`, `stop`, `epoch_cancelled`, `result`, `pause`, `resume`, `end` |
| `SpellerStimuli` | модуль → спеллер | `keyboard`, `flash`, `trial_done`, `distribution_request`, `user_stop`, `done` |
| `SpellerLikelihood` | декодер → спеллер | накопленное правдоподобие и watermark `through_flash` |

```python
while (epoch := link.wait_epoch()) is not None:
    for trial in range(n_trials):
        for group in complete_cycle(epoch):
            draw(group); pygame.display.flip(); link.flash(group)
            # Декодер обрабатывает ЭЭГ асинхронно либо модуль присылает свою оценку.
            if link.should_stop():
                break
        else:
            link.trial_done()  # Только полный цикл.
        if link.should_stop():
            break
    if not link.epoch_cancelled():
        link.done()
    result = link.wait_result()
```

Модуль можно написать на Python, PsychoPy, MATLAB, C# или другом языке — требуется
тот же обмен JSON через LSL. Python-помощник зависит только от pylsl.
