# Контракт модуля физиологии со спеллером — `speller-link@1`

Версия от 19.10.2026. Модуль физиологии полностью съёмный. Это отдельная программа (например, на pygame), которая рисует экран испытуемого и, по желанию, сама декодирует ЭЭГ. Спеллер не знает, что на экране. Обмен идёт только через три LSL-потока, поэтому модуль может работать на том же компьютере или на соседнем в той же сети.

На Python всё делает один файл `speller_link.py`; ему нужен только `pip install pylsl`. Из других языков (PsychoPy, MATLAB, C#) достаточно слать JSON-строки в LSL — см. раздел «Протокол».

## 1. Что обязательно

**Одно правило:** сразу после `flip` кадра, на котором стимул стал виден, сообщить, каких символов он касается.

```python
from speller_link import SpellerLink

link = SpellerLink(name="moya_paradigma")       # находит запущенный спеллер

pygame.display.flip()
link.flash(["А", "Б", "В"])                     # подсветилась строка; метка времени = сейчас (часы LSL)
```

- **Вспышка строки** — `link.flash(строка)`, **вспышка столбца** — `link.flash(столбец)`.
- **Начало движения буквы или кружка** (парадигмы 0.0 и 0.4) — `link.flash(["К"])`. Если в одном кадре начали двигаться несколько букв, вызовите `flash` для каждой с одной меткой времени: `t = now()`, затем `link.flash(["К"], timestamp=t)`.
- **Задержка монитора.** Если она измерена фотодиодом, передайте исправленное время: `link.flash(group, timestamp=t_flip + задержка_монитора)`.

Всё остальное — как выглядит стимуляция, сколько повторений, порядок, цвета, шрифты, второй монитор — решает модуль.

## 2. Что спеллер присылает модулю

`epoch = link.wait_epoch()` ждёт начала эпохи, то есть набора одного символа, и возвращает:

| Поле | Что это |
|---|---|
| `epoch.id` | номер эпохи |
| `epoch.symbols` | символы клавиатуры, по порядку. **Клавиатуру задаёт спеллер**: окно оператора, блок «клавиатура». Есть набор «как у Артёма» 4×11 |
| `epoch.layout` | `(строк, столбцов)`; `epoch.rows()` — символы по строкам; `epoch.cell(s)` — `(строка, столбец)` символа |
| `epoch.text` | уже набранный текст, если хотите показать его испытуемому |
| `epoch.cue` | целевая буква-подсказка. Только если оператор включил «показывать испытуемому целевую букву» (copy-spelling, калибровка); иначе `None`. **Не используйте её, чтобы решать, когда заканчивать эпоху** |
| `epoch.settings` | рекомендуемые `flash_ms`, `isi_ms`, `n_repetitions` — можно игнорировать |

Во время эпохи:
- `link.should_stop()` становится `True`, когда спеллер уже уверен в символе: апостериорная вероятность выше порога из окна оператора. Можно прекратить стимулы и перейти к следующему символу. Если не проверять, ничего не сломается, эпоха просто будет длиннее;
- `link.paused` и `link.ended` — оператор поставил паузу или завершил сессию.

После эпохи:
- `link.done()` — модуль закончил показ этой эпохи;
- `link.wait_result()` — выбранный символ (`symbol`) и весь текст (`text`), чтобы показать испытуемому.

Типичный цикл:

```python
while (epoch := link.wait_epoch()) is not None:
    if epoch.cue:
        show_cue(epoch.cue)                        # «Время показа целевой буквы/подсказки»
    for trial in range(n_trials):                  # Trial = все строки и все столбцы по разу
        for group in shuffled_rows_and_columns(epoch.rows()):
            draw(group); pygame.display.flip()
            link.flash(group)
            wait(flash_ms, isi_ms)
            if link.should_stop():
                break
        if link.should_stop():
            break
    link.done()
    show_result(link.wait_result())                # «Время отдыха после окончания эпохи»
```

## 3. Если модуль сам декодирует ЭЭГ

Декодер может быть той же программой или отдельной: `SpellerLink(name="decoder", role="decoder")`.

```python
link.send_likelihood({"А": 0.02, "Б": 0.61, ...}, epoch=epoch.id)            # промежуточная оценка
link.send_likelihood({...}, epoch=epoch.id, final=True)                       # окончательная
```

- **Что присылать:** P(ЭЭГ | задуман этот символ) — правдоподобие **без языковой модели и без частот букв**. Языковую модель спеллер добавит сам; если её учесть и у вас, она будет учтена дважды.
- **Нормировать не обязательно.** Символы, которых нет в словаре, делят оставшуюся массу поровну.
- **Обновления можно слать после каждого стимула** — тогда работает досрочная остановка.
- **Плохие данные** (артефакт, обрыв) — `usable=False`: спеллер не выберет символ и повторит эпоху.
- **Всё записывается:** спеллер пишет каждое обновление как прислано (`raw`), с временем отправки и временем прихода.

## 4. Модуль-папка и параметры в окне оператора

Положите папку в `stimulus_kit/modules/`:

```
stimulus_kit/modules/moya_paradigma/
  main.py          # точка входа, использует SpellerLink
  settings.json    # параметры (необязательно)
  module.json      # название и подсказки к параметрам (необязательно)
```

- **В окне оператора** модуль появится в списке «программа стимуляции». Параметры из `settings.json` станут полями ввода: число, да/нет, текст, цвет `[R, G, B]`. Подсказки берутся из `module.json` → `"help": {"ключ": "что это"}`; ключи, начинающиеся с `_`, — комментарии.
- **Правки оператора** действуют только на одну сессию: они сохраняются в папку сессии и передаются модулю как `--settings <файл>`. Ваш `settings.json` не меняется.
- **Ключи командной строки**, которые окно оператора умеет передавать (все необязательны):
  - `--settings <файл>`;
  - `--keyboard` — пробел вместо ЭЭГ;
  - `--windowed` — окно вместо полного экрана.
- **Рабочая папка** модуля — папка сессии (`external/module_run/`), поэтому логи модуля попадают в запись эксперимента.
- **Помощники:** `module_tools.py` даёт `module_args()` (эти три ключа), `load_settings()`, `color()`, `place_window()` (второй монитор) и `AsyncKeyboardDecoder` (пробел вместо ЭЭГ для перекрывающихся стимулов).

## 5. Готовые модули

| Модуль | Откуда | Стимул |
|---|---|---|
| `flash_rows_cols` | по описанию «Мигания» от физиологов; все параметры из описания есть в settings.json | вспышка строки или столбца |
| `artem_moving_letters` | Paradigm_0/0.0 Артёма, логика движения не тронута | начало движения буквы |
| `artem_circles` | Paradigm_0/0.4 Артёма, траектории не тронуты | начало движения кружка |

Все изменения в коде Артёма помечены комментарием `SPELLER-LINK`.

## 6. Чем это отличается от исходных программ Артёма

1. **Клавиатура** приходит от спеллера (`alphabet`, `num_rows`, `num_cols` из settings.json больше не нужны).
2. **Эпохи** идут по командам спеллера, а не по `sentence` из settings.json. Предложение-задание задаёт оператор.
3. **Эпоха стартует сама.** Старый режим «по пробелу» — параметр `start_by_space`.
4. **Метки.** Вместо `sync` раз в секунду в поток `annotations` (до `flip`) — метка на каждый стимул сразу после `flip`, в потоке `SpellerStimuli`.
5. **Конец эпохи.** Эпоха заканчивается, когда каждая буква сделала `num_samples` движений или когда пришёл `stop`. Раньше она кончалась по целевой букве — модуль не должен знать цель.
6. **Подсказка** показывается только при `epoch.cue`.
7. **Пути к логам** — `os.path.join` вместо `logs\…`, поэтому модули работают и на Linux/macOS.
8. **Фильтры и каналы** (`lowpass_filter`, `channels`…) — это параметры декодера, а не стимуляции; в модулях стимуляции их нет.
9. **«Минимальное количество нецелевых подсветок между целевыми».** Модуль не знает цель, поэтому в `flash_rows_cols` это сделано как минимум `min_gap` других подсветок между двумя подсветками одного и того же символа.

## 7. Протокол (для программ не на Python)

Три LSL-потока типа `Markers`, один канал, строки JSON:

| Поток (name) | Кто шлёт | Сообщения |
|---|---|---|
| `SpellerControl` | спеллер | `{"cmd":"epoch_start","epoch":3,"symbols":[…],"layout":[4,11],"text":"ПРИ","cue":"В"\|null,"settings":{…}}`, `{"cmd":"stop","epoch":3,"confidence":0.99}`, `{"cmd":"result","epoch":3,"symbol":"В","text":"ПРИВ"}`, `{"cmd":"pause"}`, `{"cmd":"resume"}`, `{"cmd":"end"}` |
| `SpellerStimuli` | стимуляция | `{"epoch":3,"flash":["А","Б"]}` — **метка времени LSL = момент flip**; `{"epoch":3,"event":"done"}` |
| `SpellerLikelihood` | декодер | `{"epoch":3,"p":{"А":0.1,…},"final":false,"usable":true}` |

## 8. Время

Метку вспышки ставит рисующая программа в часах LSL своего компьютера. LSL переносит её вместе со значением и пересчитывает в часы спеллера, поэтому задержка доставки на точность метки не влияет.

На одном компьютере расхождение отправленной и записанной метки меньше 1 мс. Доставка самих сообщений в проверке на синтетике: медиана 1,7 мс, 95-й перцентиль 3,4 мс.

Каждое событие спеллера тоже получает время LSL (`lsl_s`), поэтому стимулы, ЭЭГ, правдоподобия и решения спеллера лежат на одной оси. Не учтена только постоянная задержка монитора между `flip` и свечением. Её один раз меряют фотодиодом (ключ `--photodiode` в примерах) и добавляют к метке.
